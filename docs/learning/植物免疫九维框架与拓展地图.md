# 植物免疫九维框架与拓展地图

植物免疫可以按生活方式、攻击者、屏障、识别、输出、系统协调、RNA、生态环境和应用九个维度组织。学习时还需要把它们连成过程：**攻击者在什么位置活动，植物感知到什么，哪些细胞采取何种行动，病原负担与宿主损失最终怎样改变。** 本页将九维框架接入全书，并解释几处会影响后续理解的概念。

**学习目标。** 能按问题找到相应章节，区分结构分类与功能分工，解释非寄主抗性、预激代价及营养类型的适用范围。初读先完成[第0章](ch00-细胞与分子基础.md)与[侵染循环](病理基础与侵染循环.md)，再用本页规划专题阅读。

## 2　先分清结构分类与功能名称

**CNL、TNL和RNL主要描述NLR的结构与谱系；sensor、helper和executor描述研究中的功能分工。** 二者不是同一套分类。ADR1、NRG1属于RNL；茄科NRC辅助网络中的NRC成员属于CNL，不能因为发挥辅助功能就将它们写进RNL。Pik配对受体的执行分工，也不能直接等同于整个NRC或ADR1/NRG1网络。

同样，抗性基因R不是NLR的同义词。已知抗性可由表面受体、转运蛋白和其他机制产生；一种作物的NLR数量也不等于其全部免疫受体数量。基因组大小、谱系、种质和注释方法都会影响受体家族计数。[第4章](../part2-分子机制/ch04-NLR与抗病小体.md)与[Lr34研究史](../history/genes/Lr34.md)提供不同类别的例子。

| 常见速记 | 更适合继续学习的表述 |
|---|---|
| 每个细胞都有完全独立且相同的免疫系统 | 多类细胞具有防御能力，但部署受细胞身份、状态、位置与细胞间信号影响 |
| PRIMER是植物新发现的免疫细胞类型 | 它是特定叶片互作中描述的稀有免疫细胞状态；不能据此建立固定的新谱系 |
| 所有RLK都是免疫受体；所有PRR都招募同一共受体 | RLK是结构类别，PRR是功能类别；不同复合体有不同伙伴，如几丁质识别体系不能全部套用FLS2—BAK1 |
| MAMP是病原无法改变的必需成分 | 某些模式受到功能约束，但微生物可有配体变异、遮蔽或其他逃逸途径；共栖微生物也携带MAMP |
| CNL激活都形成五聚体 | ZAR1与NbNRC2已提供不同架构实例；聚合数应按具体受体说明 |
| PTI与ETI协同意味着全部输出永远缺一不可 | 共享与互相增强有明确实验支持，依赖程度仍需按受体、宿主和输出描述 |

## 3　守卫、诱饵和整合结构域要分别判断

守卫模型关注受体如何感知宿主靶标的状态；诱饵模型进一步讨论某被监测对象是否主要承担“暴露效应子活动”的任务。**没有发现其他功能，不等于已经证明完全没有生理功能。** PBS1是受RPS5监测的激酶，也是理解诱饵概念的重要例子，但不能把它简单定义为“毫无生理作用的假蛋白”。Zhang等（2010）研究了PBS1相关激酶的免疫信号联系，提示需要分别评价家族功能与被监测关系。[原始研究](https://doi.org/10.1016/j.chom.2010.03.007)

整合结构域（integrated domain，ID）则表示NLR中包含了与识别有关的附加结构域。一个ID可以直接结合效应子，也可以成为被修饰的对象；“整合诱饵”是其中一种解释，不能预先替所有ID断定其进化来源与功能。直接识别也不必然比间接识别短命，持久性还取决于配体功能约束与病原群体。具体例子见[第8章](../part3-攻防博弈/ch08-植物的识别智慧.md)。

## 4　非寄主抗性不能用“99%的微生物不致病”定义

**非寄主抗性（nonhost resistance，NHR）**通常描述一个植物物种对另一个植物物种的适应性病原所表现出的广泛不相容关系。判断它要明确宿主范围、病原身份和取样范围。向叶片加入任意土壤微生物后没有发病，还可能是微生物本来没有该致病能力、没有进入适宜部位，或环境不允许感染，不能直接给出非寄主抗性的比例。

非寄主抗性可以由多层过程共同形成。Lipka等（2005）在拟南芥研究中区分了侵入前与侵入后的防御贡献：跨越表面边界与在组织内继续发展，是两个不同关口。这也说明NHR不是“被动城墙”的另一个名字，主动感知和代谢可参与其中。[原始研究](https://doi.org/10.1126/science.1119409)

把一个关系归为非寄主，并不意味着它永远不可改变。研究对象、遗传材料与环境应写进结论；宿主范围也与病原适应有关。与[侵染循环](病理基础与侵染循环.md)配合时，可把“不形成病害”拆成没有接触、进入受阻、定殖受限与繁殖失败等具体问题。

## 5　营养类型和免疫输出之间没有统一处方

活体营养、坏死营养和半活体营养帮助我们理解资源关系，却不能单独决定每种激素或死亡反应的作用。SA、JA和ET会整合伤害、组织、发育与其他信号；同一病原的不同阶段也可能面对不同限制。不能把坏死营养病原防御写成“绝对不能出现任何细胞死亡”，也不能把对活体营养病原的保护都归结为HR把病原饿死。

| 需要连接的概念 | 应当保留的区别 |
|---|---|
| 冠菌素与茉莉酸 | 冠菌素模拟的是经典COI1—JAZ感知中的活性形式JA-Ile；不是所有JA相关化合物都相同 |
| RBOHD与过氧化氢 | RBOHD首先将电子转移给氧形成超氧阴离子，后续反应可产生过氧化氢；ROS还具有信号与损伤等多重作用 |
| 早期与晚期反应 | 它们描述常见观测窗口；信号、转录、代谢和反馈可以重叠，不能排成每株植物通用的固定分钟表 |
| 局部死亡与再生 | 植物具有再生能力，但分生组织、维管组织或繁殖器官受损可能代价巨大；HR的收益取决于互作背景 |
| 强响应与强保护 | ROS、PR1或坏死增强，都需要接回病原负担、组织损失与后续繁殖结局 |

## 6　预激是一种有条件的投资

预激（priming）强调先前事件改变了后续应答能力，不意味着静息阶段完全不耗费资源。van Hulten等（2006）比较了拟南芥中预激与直接诱导防御的成本和收益，发现二者的生长代价与病害条件下收益存在差异。这支持“较低代价的准备状态”这一思路，没有给出所有植物、所有诱导方式都零成本的定律。[原始研究](https://doi.org/10.1073/pnas.0510213103)

同样，SAR不是对任何后续病原都自动有效，也没有统一的“反应翻倍”。读论文时区分基线表达、再次刺激后的动态、病原限制和农艺表现，再看作者究竟测了哪一项。[第18章](../part6-专题与研读/ch18-系统免疫与防御预激.md)提供整株背景，挥发信号专题提供跨植株的具体例子。

## 7　九维地图之外还应追踪的四条线

1. **病理阶段与定量结局。** 识别、进入、感染、发病、传播不是同一终点；抗性、耐受性与发育造成的避病也应区分。
2. **自然变异与进化。** 受体库有种质差异，病原群体也在变化。一个基因的功能史应与宿主范围及群体选择相联系，见第6、9章与研究史系列。
3. **证据与统计。** 关联、直接作用、遗传依赖与保护结局需要不同证据；空间中相邻的多个细胞不是自动独立的生物学重复，见第20—23章。
4. **关闭、恢复与长期部署。** 有效免疫包含负反馈、蛋白周转和组织恢复；应用还包含抗性谱、品质、环境适应与病原监测，见第11、14—16章。

完成一轮学习后，选一个实例，把这四条线各补一句。这样，框架会从术语清单变成能阅读研究的知识网络。

## 自测与解析

**1. PRIMER和保卫细胞可以作为同一层次的分类并列吗？**

不宜。保卫细胞是发育与解剖学身份；PRIMER描述研究中识别的免疫状态。细胞身份与活动状态可以交叉，需要用不同证据界定。

**2. 为什么随机土壤微生物没有让叶片发病，不足以测量非寄主抗性？**

没有明确病原的适应性宿主范围、接触和感染条件，就无法排除未暴露、没有致病能力或环境不适宜等解释。

**3. NRC2是辅助NLR，因此一定属于RNL吗？**

不是。辅助是功能，NRC2属于CNL；ADR1、NRG1才是RNL家族中的代表。两套分类不能互相替代。

**4. RBOHD被激活，是否可以写成它直接合成并喷出全部过氧化氢？**

不能。它首先产生超氧阴离子，后续化学或酶促过程参与过氧化氢形成；组织中的ROS还可能有其他来源。

**5. 预激后基线PR1没有明显上升，是否说明没有成本？**

不能。单个标记不等于资源收支。成本与收益需要适合的问题、时间和生长繁殖指标共同评价。

**6. 读完九个主题后，怎样检查自己是否能用框架解释研究？**

选定宿主、攻击者与位置，写出感知入口、实际读数、保护结局及外推范围；再画出仍缺证据的一条连接，而不是只罗列缩写。

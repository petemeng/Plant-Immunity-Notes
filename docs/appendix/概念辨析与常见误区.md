# 概念辨析与常见误区

以下表格把容易混淆的概念放在一起。它适合复习，不替代各章中的机制和证据解释。

| 容易混淆的概念 | 准确区别 | 回到哪章 |
|---|---|---|
| 防御反应与抗病结局 | 前者是过程或指标，后者是特定条件下的功能结果 | 0、20 |
| 抗性与耐受性 | 抗性强调限制病原，耐受性强调在给定负担下减轻宿主损失 | 0 |
| 免疫与没有发病 | 没发病还可能来自缺少暴露或环境不适宜 | 0、12 |
| 质外体与细胞质 | 质外体位于质膜外；进入其中不等于进入细胞质 | 0、17 |
| 基因表达与蛋白活性 | RNA 水平不能替代蛋白量、修饰或功能测量 | 0、3 |
| MAMP 与“病原专属分子” | MAMP 可存在于病原、共栖或有益微生物 | 1、19 |
| PTI 与 ETI | 主要反映感知入口及历史分类，输出相互联系而非绝对隔离 | 2 |
| PRR 与 RLK | PRR 按功能定义，RLK 按蛋白结构分类；并非所有 RLK 都是免疫 PRR | 3 |
| CNL、TNL 与 RNL | 按特定结构特征分类，不能据此假定所有成员有同一种执行机制 | 4 |
| NLR 激活与 HR | 激活可产生多种输出，HR 不是所有情境下必要或充分的判据 | 4 |
| 2019 年 ZAR1 结构与 2021 年通道功能 | 结构提供组装和构象证据，功能研究检验离子通透等性质 | 4、20 |
| SA 与 JA | 既可能拮抗，也存在条件依赖的配合，不能一律二选一 | 5 |
| 甘油-3-磷酸与甘油醛-3-磷酸 | 两种不同化合物；SAR 语境下 G3P 通常指前者 | 5、18 |
| 局部诱导与远端保护 | 远端分子标记改变还需与功能性保护证据衔接 | 18 |
| SAR、ISR 与预激 | 前两者涉及诱导抗性的特定研究语境；预激描述后续应答能力的状态 | 18 |
| 信号移动与远端合成 | 远端积累不单独证明同一分子由局部运来 | 18 |
| 后代效应与稳定跨代记忆 | 亲代营养、种子资源或微生物传递等也可能影响后代 | 18 |
| 凯氏带与木栓质 | 是内皮层中不同结构特征，形成位置与调控不能混为一谈 | 19 |
| 细胞类型与细胞状态 | 前者强调身份，后者强调特定条件下的活动，可交叉分布 | 19、20 |
| 根与叶共享信号与响应完全一致 | 共享分子并不保证组织部署、时间和输出相同 | 19 |
| 相对丰度与绝对数量 | 比例升高也可能来自其他成员减少 | 10、20 |
| 有益菌与永久有益 | 效果依赖菌株、宿主、营养和群落背景 | 10、15、19 |
| 必要性与直接作用 | 一个因素影响结果，不代表它直接结合或催化另一个因素 | 20 |
| 共定位、共复合体与直接结合 | 三类证据的物理解释不同，不能互相替代 | 20 |
| 技术重复与生物学重复 | 重复测量同一样本不能增加独立生物来源 | 20 |
| 统计显著与实际重要 | 效应大小、精度和生物意义需要分别判断 | 20 |
| 机制可行与应用可靠 | 还需考虑遗传背景、环境、代价和长期稳定性 | 14、15 |

## 一个通用的纠错练习

遇到“X 增强免疫”这样的句子，可以依次补足：X 是什么；在哪一种植物、哪类组织中；与什么比较；测到哪一种输出；是否有疾病结局；结论可外推到哪里。

例如，“某样本防御标记增加”是一个观察；“某条通路被激活”是一种需要更多背景支持的解释；“该材料适合广泛应用”则是更远的外推。把它们分开后，句子通常会更准确，也更容易理解。

# 前言

这本书聚焦植物免疫的科学逻辑、研究思路和重要创新发现。

写作目标：

1. 讲清机制背后的“为什么”
2. 讲清重大突破的思维路径
3. 讲清认知如何演变与修正
4. 讲清争议和未解问题

建议阅读顺序：

- 先读 Part 1 建立框架
- 再读 Part 2 和 Part 3 进入核心机制与攻防逻辑
- 最后读 Part 4 和 Part 5 形成前沿与转化视角

## 2025–2026 更新说明

本轮修订补入了最新前沿文献，重点覆盖 PRR 与 NLR 工程、BIK1 底物图谱、helper NLR 抗病小体簇、JA 系统免疫、根分泌物驱动的微生物组记忆，以及跨界 RNA 调控。

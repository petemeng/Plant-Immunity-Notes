# 拟南芥模式系统贯穿案例：从感知细菌到判断抗病

把FLS2、BIK1、RBOHD、NPR1分别背熟，仍可能不知道一篇论文为什么同时展示ROS、基因表达和细菌负担。本专题以**拟南芥—丁香假单胞菌互作**为主线，把进入部位、受体感知、信号输出、病原限制和系统保护连起来。学习目标是建立一张能解释证据的地图，而非把所有机制画成一条直线。

**先修与成果。** 先读[病理基础与侵染循环](病理基础与侵染循环.md)。完成后，交出三份学习成果：一张有细胞区室的分子地图、一张按问题组织的证据表、一段限定对象与条件的抗病结论。需要补分子基础时返回[第0章](ch00-细胞与分子基础.md)。

## 1　先把模式系统中的名字认清

拟南芥是宿主植物，*Arabidopsis thaliana*是物种名，Col-0是常见参考种质；*fls2*、*bik1*等通常指特定宿主遗传材料，不能用它们代替物种名。*Pseudomonas syringae* pv. *tomato* DC3000中的DC3000则是菌株标识，常简称Pst DC3000。

这一细菌最初与番茄病害研究相联系，也被用于拟南芥实验互作。**一个模式系统的研究便利，不等于其中每种受体关系都是所有作物的共同规律。** 同属细菌的不同菌株、同种植物的不同种质，以及组织和环境变化，都可能改变结局。经典系统综述提供了宿主遗传学与细菌互作的背景（Katagiri et al., 2002）。[原文](https://doi.org/10.1199/tab.0039)

| 名称 | 属于哪个层次 | 初学者应避免的混淆 |
|---|---|---|
| 拟南芥 / *A. thaliana* | 宿主物种 | 不能默认代表全部植物 |
| Col-0 | 参考种质 | 不同种质的NLR与抗性背景可能不同 |
| *fls2*等 | 宿主遗传材料 | 名称本身没有告诉你全部背景与剩余功能 |
| Pst DC3000 | 指定细菌菌株 | 不能与其他丁香假单胞菌菌株互换 |
| flg22 | 用于研究感知的鞭毛蛋白相关分子线索 | 对一个线索的反应不等于对完整细菌的全部反应 |
| AvrRpt2、AvrRps4等 | 不同的效应子身份 | 识别取决于相应宿主受体和研究背景 |

## 2　第一幕：细菌在哪里，植物先遇到什么

从叶表走进叶片，先要跨越空间边界。角质层、气孔及其保卫细胞，与叶肉细胞之间的质外体，是不同的生活环境。细菌出现在叶表时，叶内细胞的反应与它是否已经进入组织不能混为一谈。气孔防御研究说明，进入机会本身就是宿主能够调节的一部分（Melotto et al., 2006）。[原始研究](https://doi.org/10.1016/j.cell.2006.06.054)

练习读论文时，在每张图旁先写“叶表”“叶内”或“尚不能定位”。如果某项比较绕过了自然进入边界，它可以很好地研究叶内限制，却不能单独说明角质层或气孔的贡献。反过来，气孔关闭也不是细菌负担必然下降的完整解释，因为病原与宿主在叶内还有后续互作。

这一步连接[第17章屏障与化学防御](../part6-专题与研读/ch17-屏障与化学防御.md)。看懂它之后，才更容易理解为什么免疫并不是从一个胞内受体被激活的瞬间才开始。

## 3　第二幕：用FLS2学习“感知”与“受体复合体”

FLS2相关研究逐步回答了三个问题：缺少这个基因，特定响应是否受损？该蛋白与配体是否有物理联系？配体状态怎样改变与BAK1等伙伴的关联？这些问题分别需要遗传、生化和复合体证据。

从[第23章FLS2遗传案例](../part7-研究技术与实验逻辑/ch23-遗传学与免疫表型研究技术.md#case-fls2-genetics)开始，再读[第21章Co-IP原图](../part7-研究技术与实验逻辑/ch21-蛋白质相互作用研究技术.md#case-coip)。前者帮助判断表型归因，后者显示输入、诱饵捕获和伙伴共沉淀如何分工。两张图来自不同阶段和不同研究，不能把后来图中的泳道当成最初发现实验。

| 证据问题 | 代表研究入口 | 能推进到哪一步 |
|---|---|---|
| 特定感知响应是否需要FLS2？ | Gómez-Gómez & Boller（2000）[DOI](https://doi.org/10.1016/S1097-2765(00)80265-8) | 将响应缺陷与基因身份联系起来 |
| FLS2是否与配体有特异物理联系？ | Chinchilla等（2006）[DOI](https://doi.org/10.1105/tpc.105.036574) | 支持受体身份，补足遗传证据没有直接回答的结合问题 |
| BAK1怎样进入受体相关信号？ | Chinchilla等（2007）[DOI](https://doi.org/10.1038/nature05999) | 用关联与植物响应连接共受体功能 |
| 复合体关联与激酶催化是否同一命题？ | Schwessinger等（2011），本书图21.2 [DOI](https://doi.org/10.1371/journal.pgen.1002046) | 进一步拆分组装与催化能力 |

这一幕最重要的学习成果，是把“受体很重要”“直接结合”“与伙伴同复合体”“传递信号”写成四个不同命题。

## 4　第三幕：受体怎样接上ROS、钙与MAPK

受体附近的胞质激酶，如BIK1，可以把感知状态连接到下游靶点。RBOHD参与质膜相关的活性氧产生，钙通道及钙结合蛋白参与离子信号，MAPK模块参与蛋白修饰与转录调节。这些事件既有分支，也有反馈；画图时应允许从一个节点分出多条箭头。

在[第3章](../part2-分子机制/ch03-受体与信号转导.md)中，先找出哪些箭头有直接磷酸化证据，哪些主要是遗传依赖。随后进入[ROS/MAPK真实原图](../part7-研究技术与实验逻辑/ch23-遗传学与免疫表型研究技术.md#case-ros-mapk)，练习分别读曲线和条带。该例具体研究的是NIK相关宿主材料；它可以训练读数逻辑，但不能代替BIK1直接作用的证据。

| 看见的结果 | 首先能说什么 | 还要问什么 |
|---|---|---|
| ROS相关发光曲线改变 | 指定体系中的氧化相关动态改变 | 来源、探针与组织状态是否可比？ |
| 钙报告荧光改变 | 指定区室中的钙相关读数改变 | 基线、报告量和空间平均是否影响解释？ |
| 磷酸化MAPK条带改变 | 修饰相关信号改变 | 对应目标总蛋白是否也改变？ |
| 某防御基因RNA上升 | 相应转录本丰度改变 | 是直接调控，还是网络状态变化的结果？ |

进一步读[钙信号与细胞死亡原图研读](../part7-研究技术与实验逻辑/钙信号与细胞死亡原图研读.md)，比较植物组织中的空间传播与单条平均曲线。该专题中的机械感知与本幕的flg22入口不同，迁移的是读图方法，不是把两种刺激强行视为同一机制。

## 5　第四幕：完整细菌互作中的效应子与ETI

完整细菌带来的线索比单一flg22丰富，也会通过效应子影响宿主状态。植物若具有能够识别某效应子或其作用的受体，便可能启动相应的ETI。是否发生识别，取决于具体的效应子—受体匹配，不能因为标签写着DC3000，就默认所有NLR都被激活。

例如，讨论RPS2时要核对AvrRpt2相关识别背景；讨论RRS1/RPS4时则是另一套匹配关系。这种匹配可用于解释已发表实验的比较，不应把不同受体、菌株背景和效应子条件混成同一个“标准ETI”。有关直接与间接识别，参见[第8章](../part3-攻防博弈/ch08-植物的识别智慧.md)。

2021年的研究把细胞表面受体与胞内受体的功能联系起来，显示特定体系中的互相增强和遗传依赖（Ngou et al., 2021；Yuan et al., 2021）。读两篇论文时，在笔记中分别写出“受体入口”“宿主背景”“所测输出”。这样既能理解协同模型，也能保留它的适用范围。[Ngou原文](https://doi.org/10.1038/s41586-021-03315-7) · [Yuan原文](https://doi.org/10.1038/s41586-021-03316-6)

## 6　第五幕：激素把局部信号变成持续的防御状态

在拟南芥的许多细菌互作研究中，SA合成与NPR相关调控是重要部分。把ICS1/SID2、SARD1/CBP60g和NPR1放到地图上时，应区分合成酶、转录调控因子和信号调节蛋白。一个名字参与“SA通路”，不代表它们在做同一种工作。

JA和ET同样参与互作，且与发育、伤害和其他防御过程相连。不要仅凭病原的营养类型，就把一种激素从地图中删除；也不要看到PR1上升就把全部变化归为SA直接作用。可对照[第5章](../part2-分子机制/ch05-激素信号网络.md)与[真实WRKY70表达案例](../part7-研究技术与实验逻辑/ch22-表达定位与转录调控研究技术.md#case-qpcr)，分别学习网络背景和归一化读数。

这里的关键转折是：短暂的受体激活、较晚的RNA变化和整株状态之间，需要时间与功能证据衔接。把三者画在一条箭头上，是待解释的模型，不是证明已经结束。

## 7　第六幕：最后怎样判断“抗病”

最终结局至少有两个轴：**病原负担**与**宿主损失**。病原更少支持限制能力改变；相同负担下损失更小，则更接近耐受性问题。病斑、鲜重、叶片死亡与可培养细菌数量，不能任意互相替代。

读细菌负担图时，先看单位与对数标尺，再看较早与较晚的观察。较早比较可以帮助理解起始差异，较晚比较关注后续结果。某个终点的负担不同，不等于已经获得连续的“生长速率”；同样，较早未检出差异，也不证明所有进入与分布完全一致。

可以直接练习[第23章IDD4 Figure 1](../part7-研究技术与实验逻辑/ch23-遗传学与免疫表型研究技术.md#case-complementation)。它同时显示宿主材料、表达检查、生长表型及病原负担，适合把“互补加强归因”与“所有条件完全恢复”分开。特别比较I和J的统计字母：同一材料在两项比较中的恢复程度可以不同。

## 8　第七幕：把局部关系放到整株中

当研究转向SAR，问题变成局部事件是否改变远端保护。局部PR1升高、远端某代谢物增加和远端病原负担下降，是三类需要分别连接的观察。若要主张某分子从局部移动至远端，还需运输方面的证据。

沿着[第18章](../part6-专题与研读/ch18-系统免疫与防御预激.md)阅读SA—NPR1与NHP—FMO1网络，再与[第26章ISR](../part8-免疫与微生物/ch26-有益微生物与诱导抗性.md)对照。两者都涉及系统保护，但诱导起点、信号依赖与预激方式需要按体系描述。

## 9　完成一张细胞地图和一张证据表

先画细胞壁、质膜、细胞质、细胞核与叶绿体，再逐步填入下表。第一次只画功能，第二次再填缩写。某蛋白的定位可能随状态变化，表格提供的是学习起点。

| 先填的功能 | 再填分子或模块 | 给箭头补上的证据类型 |
|---|---|---|
| 表面感知与共受体 | FLS2—BAK1 | 配体结合、关联和功能分别有什么证据？ |
| 近膜信号连接 | BIK1等RLCK | 哪一项是直接修饰，哪一项是遗传依赖？ |
| 氧化输出 | RBOHD | 蛋白状态与ROS读数是否被分别检查？ |
| 钙与蛋白激酶信号 | 通道、钙传感器、MAPK | 区室、时间和蛋白总量是否匹配？ |
| 胞内识别与执行 | 特定NLR及所需伙伴 | 是否核对了受体—效应子匹配？ |
| 激素与核内转录 | ICS1、NPR1、TGA等 | 合成、感知和转录输出是否混在一起？ |
| 远端准备与保护 | SA/NHP相关网络 | 是否真正检测了远端抗病结局？ |

接着为一篇论文填写：“改变了什么→直接测到了什么→关键对照→支持的结论→尚存解释”。至少保留一条问号箭头，注明它需要什么证据。最后用一分钟解释整张图；如果只能念缩写，就返回功能一列重画。

## 自测与解析

**1. flg22响应缺陷能否直接等同于对完整DC3000的全部免疫丧失？**

不能。完整互作包含其他线索、效应子、进入部位和宿主网络。特定感知入口的缺陷，必须通过完整互作结果继续判断。

**2. FLS2与BAK1的Co-IP阳性，是否已经证明两者独自构成了完整信号系统？**

没有。它支持所测背景中的关联；直接接触、其他伙伴及下游执行仍有各自的证据要求。

**3. 两个基因型的ROS不同、MAPK相近，是否说明实验互相矛盾？**

不一定。不同分支可以有不同依赖，检测时间与尺度也可能不同。应先明确各项测量，再讨论共同机制。

**4. 论文写“DC3000相关处理”，为什么仍要检查具体识别背景？**

菌株名称没有包含全部效应子条件与宿主受体组成。特定ETI需要对应的识别匹配，不能默认任意NLR都被激活。

**5. 某材料病斑较小，但病原负担未下降，能否立即写“抗性更强”？**

不能。可能涉及耐受性或其他宿主状态。应把组织损失与病原限制分别描述，并检查测量的灵敏度和时间。

**6. 局部与远端都出现PR1上升，是否足以证明系统获得性抗性？**

不足。还需要远端保护结果；若进一步主张信号移动，也要有与运输相匹配的证据。

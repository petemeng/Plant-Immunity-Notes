  <!-- ======== 引言 ======== -->
  <div class="chapter-intro">
  <p>前面的章节分别讨论了植物的防御工具（PTI、ETI、激素网络）和病原的攻击工具（效应蛋白）。但这些工具不是凭空出现的——它们是植物与病原在数亿年共进化中相互塑造的产物。本章将视角从分子机制提升到<strong>进化动力学</strong>，探讨攻防博弈在时间维度上如何展开。</p>

  <p>我们将看到，实验室中观察到的每一个 R-Avr 配对关系，都是一场漫长进化博弈的"快照"；田间每一次 R 基因被"突破"的事件，都是这场博弈的最新一幕。理解这种动态，不仅是学术兴趣，更是设计持久抗病策略的前提——因为<strong>抗性部署需要同时考虑病原群体变化与宿主的生理代价</strong>。</p>
  </div>

  <!-- ======== 9.1 军备竞赛的基因组证据 ======== -->
  <h2><span class="section-num">9.1</span>"军备竞赛"的基因组学证据</h2>

  <p>第6章讨论了 NLR 进化和军备竞赛/堑壕战模型的概念框架 <span class="cross-ref">→ 第6章</span>。本节聚焦于基因组学层面的直接证据——共进化的"指纹"如何被刻写在基因组中。</p>

  <h3>效应蛋白与 NLR 的协同进化印记</h3>
  <p>共进化在基因组中留下了可辨识的分子印记：</p>
  <ul>
    <li><strong>NLR 的选择印记：</strong>部分 NLR 的 LRR 位点显示非同义替换相对于同义替换富集，支持这些位点经历多样化选择（Mondragón-Palomino et al., 2002）。这不等于所有 LRR 的整体 dN/dS 都大于 1；重组、序列比对和所用进化模型也会影响估计。LRR 的功能还包括受体调控，不能把全部选择信号都解释成直接结合病原分子。</li>
    <li><strong>效应蛋白基因的"两速"基因组：</strong><em>Phytophthora infestans</em> 的基因组呈现惊人的"两速"（two-speed）结构——基因密集的保守区域和基因稀疏但转座子丰富的快速进化区域。效应蛋白基因（RXLR 和 CRN 家族）在快速进化区域中富集，这使得效应蛋白的获取、丢失和多样化速率远高于其他基因 (Raffaele et al., 2010; Dong et al., 2015)。</li>
    <li><strong>稻瘟菌 AVR-Pik 与水稻 Pik 的对应进化：</strong>AVR-Pik 的多个等位变异（如 AVR-PikA、AVR-PikD）与 Pik 的多个等位（Pikp、Pikm、Pikh 等）之间存在精确的识别/逃逸对应关系——某些 AVR-Pik 变异能逃避特定 Pik 等位的识别但被其他等位识别。这种"棋盘式"的匹配/不匹配模式支持识别特异性经历共同演化，但单一时间点的配对矩阵不能独自重建演化先后顺序 (Kanzaki et al., 2012; De la Concepcion et al., 2021)。</li>
  </ul>

  <h3>基因组级共进化的新证据</h3>
  <p>近年来，全基因组关联研究（GWAS）和泛基因组分析为共进化提供了群体水平的系统性证据。Karasov et al. (2014) 对拟南芥自然群体中免疫基因变异与本地病原群体毒力的关联分析显示：同一地理区域内的植物群体和病原群体之间存在<strong>局部适应</strong>（local adaptation）的信号——即各自"定制"的攻防配置。这种局部适应是共进化的生态学表现。</p>

  <!-- ======== 9.2 Boom-and-bust ======== -->
  <h2><span class="section-num">9.2</span>从 Boom-and-Bust 到持久抗性的思考</h2>

  <p>共进化理论对农业实践最直接的冲击是：<strong>单基因 R 基因的大面积部署几乎必然会被突破</strong>。</p>

  <h3>Boom-and-Bust 循环</h3>
  <p>"繁荣-崩溃"（Boom-and-Bust）循环是农业中反复上演的故事：</p>
  <ol>
    <li><strong>Boom（繁荣期）：</strong>一个新的 R 基因品种被培育并大面积推广，对当前流行的病原小种表现出优异的抗性。</li>
    <li><strong>选择压力集中：</strong>数百万亩同一 R 基因的部署创造了巨大的定向选择压力——能够克服该 R 基因的病原突变体具有极大的适应度优势。</li>
    <li><strong>Bust（崩溃期）：</strong>经过不同长度的时间后，能够逃避该 R 基因识别的病原新小种在群体中扩张，R 基因"失效"，抗性品种变为感病品种。</li>
    <li><strong>新循环：</strong>育种家引入新的 R 基因品种，循环重新开始。</li>
  </ol>

  <h3>从单基因到持久抗性</h3>
  <p>如何打破 Boom-and-Bust 循环？主要策略包括：</p>
  <ul>
    <li><strong>R 基因堆叠（gene stacking/pyramiding）：</strong>将多个 R 基因同时导入一个品种。病原需要同时突变多个 Avr 基因才能克服所有 R 基因——概率随堆叠数量指数下降 (Zhu et al., 2023)。但堆叠也面临挑战：自身免疫风险（NLR 间不兼容性）、适应度代价积累、以及病原通过水平基因转移一次性获取多个新效应蛋白的可能 <span class="cross-ref">→ 第6章 6.4节</span>。</li>
    <li><strong>品种混播（cultivar mixture）：</strong>在同一田块中混合种植携带不同 R 基因的品种。这在群体水平模拟了自然群体的遗传多样性，通过频率依赖效应减缓病原适应 (Zhu et al., 2000)。</li>
    <li><strong>定量抗性（quantitative resistance）：</strong>由多个微效基因共同控制的抗性，每个基因单独效果小但叠加后显著。定量抗性因为没有单一的"突破靶标"，通常比单基因抗性更持久 (Poland et al., 2009)。</li>
    <li><strong>PRR 工程化：</strong>由于 PAMP 的高度保守性，PRR 介导的抗性在理论上比 NLR 抗性更持久——病原要逃避 PRR 识别就必须改变其核心保守分子 <span class="cross-ref">→ 第14章</span>。</li>
  </ul>

  <!-- ======== 9.3 宿主范围 ======== -->
  <h2><span class="section-num">9.3</span>宿主范围的决定因子</h2>

  <p>为什么<em>P. syringae</em>的不同致病变种（pathovar）只能侵染特定的宿主？为什么<em>M. oryzae</em>的一些专化型只侵染水稻而另一些只侵染小麦？宿主范围——即一个病原能够成功侵染的宿主物种或品种范围——是共进化的直接产物。</p>

  <h3>宿主范围的分子基础</h3>
  <p>宿主范围的决定因子可以从两个方向理解：</p>
  <ul>
    <li><strong>从病原侧：</strong>能否接触并利用植物组织，取决于其生活史、营养需求和与宿主互作的多种特征。效应子与免疫的相容性只是其中一层，不能代表全部感染条件。</li>
    <li><strong>从宿主侧：</strong>一个宿主对某个病原的易感性取决于其免疫网络是否有被该病原效应蛋白组有效抑制的"缺口"。如果宿主的 PRR 库、NLR 库和激素网络在面对该效应蛋白组时没有显著的未覆盖区域，则该病原难以建立感染。</li>
  </ul>

  <p>Schulze-Lefert &amp; Panstruga (2011) 讨论了宿主亲缘关系、非宿主抗性与病原专化之间的联系。理解这一框架时，应同时考虑物理和化学屏障、营养相容性、免疫识别、组织环境等限制。<strong>不能把非宿主抗性等同于某一个 NLR，也不能把宿主范围简化为效应子数量或免疫抑制能力的单一阈值。</strong>病害观察还要区分进入组织、短暂存活、建立持续感染与完成生活史等不同结局。</p>

  <!-- ======== 9.4 线虫共进化 ======== -->
  <h2><span class="section-num">9.4</span>线虫与植物的协同进化特点</h2>

  <p>植物寄生线虫与宿主的共进化有一些独特的特征，使其与微生物病原的共进化有所不同：</p>

  <ul>
    <li><strong>世代时间与生活史：</strong>植物寄生线虫与微生物具有不同的繁殖节律。但世代时间不能单独决定实际演化速率；种群大小、遗传变异、选择强度与休眠阶段也很重要，不能据此推断线虫的效应子多样性必然更低。</li>
    <li><strong>有性生殖的影响：</strong>胞囊线虫通常进行有性生殖，这加速了效应蛋白等位的重组和新组合的产生。但根结线虫的许多物种是孤雌生殖的，这限制了遗传多样性的产生但可能有利于通过基因复制快速扩展效应蛋白家族。</li>
    <li><strong>营养位点的依赖性：</strong>线虫对宿主巨细胞/合胞体的绝对依赖意味着，任何破坏营养位点维持的宿主突变都可能提供抗性——这创造了一个不同于微生物病原的选择压力格局 <span class="cross-ref">→ 第7章 7.4节</span>。</li>
  </ul>

  <!-- ======== 9.5 复合侵染 ======== -->
  <h2><span class="section-num">9.5</span>复合侵染场景下的协同进化</h2>

  <p>自然环境中，植物通常同时面对多种病原——而非实验室中的"单一病原挑战"。这种<strong>复合侵染</strong>（co-infection / multiple infection）场景对共进化动力学有深刻影响。</p>

  <h3>竞争与促进：病原间的互作</h3>
  <p>共同侵染同一宿主的多种病原之间可能存在竞争或促进关系：</p>
  <ul>
    <li><strong>竞争：</strong>两种病原竞争相同的宿主资源（营养、空间），导致各自的增殖受到限制。</li>
    <li><strong>促进：</strong>先发生的组织损伤或防御状态改变，有时会改变后续感染的结局。方向依赖具体宿主、病原与时间顺序，不能仅凭 SA–JA 拮抗就预测第二种病原一定获益。需要把各自单独出现与共同出现时的结果区分开来。</li>
  </ul>

  <h3>微生物组背景下的共进化</h3>
  <p>更深层地说，植物面对的不是一个病原，而是一个包含数千物种的微生物群落。在微生物组背景下，共进化的单位可能不是"一种植物 vs 一种病原"，而是"植物的免疫表型 vs 微生物群落的功能组成"。这一认识正在改变我们理解和管理植物健康的方式 <span class="cross-ref">→ 第10章, 第15章</span>。</p>

  <!-- ======== Key Question ======== -->
  <div class="box box-cognition"><div class="box-title">Key Question</div>
  <p><strong>能否通过监测病原群体的进化轨迹来预测 R 基因的"保质期"？</strong></p>
  <p>如果能实时监测田间病原群体中效应蛋白等位的频率变化（通过对病原群体的定期测序和效应蛋白组分析），理论上可以在 R 基因被大规模突破之前检测到"预警信号"——如能逃避识别的效应蛋白等位频率开始上升。这种"病原群体监测"策略类似于流感病毒的基因组监测，已在概念上被提出 (McDonald &amp; Linde, 2002)，并已用于若干作物病害的监测；不同病害的覆盖范围和预测能力仍不一致。挑战包括：采样密度、基因型-表型映射的不完整性、以及病原群体进化的随机性。</p>
  </div>

  <!-- ======== 里程碑 ======== -->
  <h2><span class="section-num">9.6</span>里程碑研究思路拆解</h2>

  <h3>研究框架：Burdon &amp; Thrall (2009) — 自然群体中的植物与病原共进化</h3>
  <div class="box box-experiment"><div class="box-title">思路拆解</div>
  <p><strong>面对的问题：</strong>绝大多数植物免疫研究在实验室中进行。共进化理论在自然群体中是否成立？抗性和毒力频率的波动是否可以被直接观测到？</p>
  <p><strong>关键思路：</strong>这是一篇综合自然系统证据的短篇综述，不是单独报告一次长期实验的原始研究。其价值在于把宿主抗性、病原变异及空间异质性放在同一个生态进化框架中讨论。</p>
  <p><strong>证据如何阅读：</strong>综述汇集的自然群体资料提示，互作随地点和时间变化。判断具体研究是否支持负频率依赖选择或局部适应，仍需检查其原始群体数据、适合度比较与替代模型。</p>
  <p><strong>影响：</strong>帮助读者理解共进化具有地点和时间依赖性。具体采样年限、位点频率和统计检验应追溯其引用的原始研究，不能直接归为这篇综述的新数据。</p></div>

  <h3>里程碑 2：Raffaele et al. (2010) — 卵菌的"两速基因组"</h3>
  <div class="box box-experiment"><div class="box-title">思路拆解</div>
  <p><strong>面对的问题：</strong><em>Phytophthora</em> 基因组异常庞大（~240 Mb），且效应蛋白基因数量惊人（>500 RXLR）。这种基因组结构是如何进化的？</p>
  <p><strong>关键思路：</strong>通过比较基因组学分析基因密度、转座子含量和进化速率在基因组不同区域的分布。</p>
  <p><strong>关键证据链：</strong>（1）基因组呈明显的"两速"分区：基因密集-进化缓慢区域 和 基因稀疏-转座子丰富-进化快速区域；（2）效应蛋白基因在快速进化区域中富集；（3）快速区域的高重组率和转座子活性促进了效应蛋白的快速多样化。</p>
  <p><strong>影响：</strong>揭示了病原如何通过基因组架构"设计"加速效应蛋白进化，为理解病原侧的共进化机制提供了基因组学框架。"两速基因组"概念后来被推广到多种丝状病原中。</p></div>

  <h3>里程碑 3：Zhu et al. (2000) — 品种混播降低病害的田间证据</h3>
  <div class="box box-experiment"><div class="box-title">思路拆解</div>
  <p><strong>面对的问题：</strong>遗传多样性在理论上可以减缓病原适应，但在实际田间条件下效果如何？</p>
  <p><strong>关键思路：</strong>在中国云南省进行了大规模（3342公顷）田间试验：将感病的糯稻品种与抗病的杂交稻品种混合种植，与单一品种种植对照。</p>
  <p><strong>关键证据链：</strong>Zhu et al. (2000) 报告，在研究的云南水稻体系中，品种混种伴随感病品种病害严重度降低和产量改善。它直接支持的是该种植体系的病害管理效果；传播阻隔、冠层微环境与选择压力的相对贡献仍须分别评价，不能把防效直接等同于病原进化已被减慢。<a href="https://www.nature.com/articles/35021046">原始研究</a>。</p>
  <p><strong>影响：</strong>首次在大田规模上证明品种多样性可以有效控制病害，为基于进化原理的抗病管理策略提供了实践验证。</p></div>

  <!-- ======== 争论 ======== -->
  <h2><span class="section-num">9.7</span>当前争论与未解问题</h2>
  <ul class="questions-list">
    <li><strong>如何用分子参数预测 R 基因的田间"寿命"？</strong>给定一个 R 基因的分子机制（直接识别 vs 间接识别）和当前病原群体的效应蛋白组多样性，能否估计该 R 基因被突破的预期时间？</li>
    <li><strong>气候变化会如何改变共进化的速率和方向？</strong>温度升高可能加速病原世代周转、改变宿主范围、或影响免疫信号通路的效率 <span class="cross-ref">→ 第12章</span>。</li>
    <li><strong>多病原并存的"博弈论"最优策略是什么？</strong>当植物同时面对活体营养型和坏死营养型病原时，SA-JA 拮抗使其无法同时最优化两条防御通路。群体水平的最优策略是否是维持激素响应的多样性？</li>
    <li><strong>如何从已有纵向资料识别相互选择？</strong>需要联合宿主和病原的遗传记录、环境背景与群体历史，区分真正的共同演化与仅发生在一方的适应。</li>
  </ul>

  <!-- ======== 实验方法 ======== -->
  <h2><span class="section-num">9.8</span>关键实验方法</h2>
  <table><thead><tr><th>实验方法</th><th>原理与用途</th><th>关键参数与注意事项</th><th>经典文献</th></tr></thead><tbody>
  <tr><td>纵向群体采样与基因分型</td><td>在自然群体或田间群体中进行多年连续采样，追踪 R 基因和 Avr 基因频率的时间变化。是验证共进化模型预测的核心方法。</td><td>代表性、时间覆盖和不确定性决定推断强度；样本量依据效应与变异评估，不能套用一个固定下限。</td><td class="ref">Burdon &amp; Thrall, 2009, Science</td></tr>
  <tr><td>病原效应蛋白组（effectome）群体分析</td><td>对病原田间群体进行基因组测序，清点效应蛋白基因的存在/缺失变异和等位多态性。用于评估病原的"逃逸潜力"。</td><td>需要覆盖足够的地理和时间范围；效应蛋白的预测依赖已知基序（T3SS 信号、RXLR 等）；需要区分假基因和功能基因。</td><td class="ref">Yoshida et al., 2013, eLife</td></tr>
  <tr><td>田间品种混播/轮作试验</td><td>在实际农田条件下测试品种多样性策略对病害控制的效果。包括混播（空间多样性）和轮作（时间多样性）。</td><td>独立重复和合适的比较对象比面积本身更重要；需考虑地块、年份、病害基线与管理方式差异。</td><td class="ref">Zhu et al., 2000, Nature</td></tr>
  <tr><td>历史与纵向数据的进化模型比较</td><td>比较不同时间、地点记录中的抗性与病原群体变化，评价定向选择、频率依赖选择和遗传漂变的解释。</td><td>观测到频率变化不自动等于相互选择；应考虑迁移、采样偏差与环境变化。</td><td class="ref">Brockhurst &amp; Koskella, 2013, Trends Ecol Evol（方法学综述）</td></tr>
  </tbody></table>

  <section class="learning-review" id="ch9-learning-review"><h2>学习整合：把“相互作用”与“共同演化”分开</h2><p>一个受体能识别一个分子，说明两者在当前条件下具有功能关系。要进一步说双方共同演化，还需证据支持：宿主的遗传变异改变病原的相对繁殖成功，病原的遗传变异也反过来改变宿主的相对繁殖成功。仅观察一方适应，或双方基因都很丰富，并不足以完成这一推断。</p><table><thead><tr><th>概念</th><th>变化的对象</th><th>不能直接推出什么</th></tr></thead><tbody><tr><td>生理可塑性</td><td>同一个体的表达或代谢状态</td><td>不能直接推出等位基因频率改变</td></tr><tr><td>定向选择</td><td>某类遗传变异的频率持续上升</td><td>不意味着优势将永久保持</td></tr><tr><td>负频率依赖选择</td><td>一种类型的收益随自身变常见而下降</td><td>不是任何频率波动都由它导致</td></tr><tr><td>地理镶嵌</td><td>不同地点的互作与选择方向</td><td>一个地点的结果不能代表整个物种</td></tr></tbody></table><p>可以用一个不带真实病原参数的概念例子理解：某种抗性在群体中罕见时，维持它的防御收益可能大于成本；当它变常见后，群体生态条件与病原组成可能改变，其相对收益也会变化。但要证明这就是负频率依赖，仍需排除天气、迁入与遗传漂变。模型的作用是产生相互竞争的解释，而不是给每一条波动曲线贴上现成标签。</p><p>读到“持久抗性”时，应同时追问持续了多久、在哪些区域、接触过怎样的自然病原群体。长期记录是证据；无限期有效则是无法由现有观察保证的承诺。</p><h3>理解检查与参考答案</h3><p>先尝试用自己的话回答，再展开解释。</p><details><summary>1. 同一地点连续两年抗性基因频率改变，能否证明共同演化？</summary><p><strong>参考答案与解释：</strong>不能。迁移、随机漂变和环境选择也可改变频率。需要同时考察双方遗传变化及其相互造成的适合度影响。</p></details><details><summary>2. 为什么识别范围广不等于抗性一定持久？</summary><p><strong>参考答案与解释：</strong>识别范围描述被检测对象的覆盖面，持久性描述跨时间和实际群体背景的效果，二者是不同维度。</p></details><details><summary>3. 为什么混种降低病害不能直接证明病原进化减慢？</summary><p><strong>参考答案与解释：</strong>病害也可因接触机会、空间阻隔或冠层微环境改变而降低。演化结论需要群体遗传与时间证据。</p></details><p class="evidence-note">本节概念例子用于训练推理；文中数值若未标注为原始研究数据，不应当作真实实验结果。全章的研究方法介绍用于阅读与证据判断，不构成操作流程。</p></section>

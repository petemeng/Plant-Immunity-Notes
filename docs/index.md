# 植物免疫学：从基础概念到机制与证据

植物不能逃离生长的位置，却能感知周围的变化，限制病原带来的损伤，与许多微生物长期共处，并在防御与生长之间不断调整。理解植物免疫，就是逐步理解细胞和组织中的识别、信号与执行过程怎样连接，又为什么不能脱离环境和进化背景。

本书面向第一次系统学习植物免疫的读者，也为具有分子生物学基础的学生提供深入阅读的入口。正文从细胞和分子语言讲起，逐步进入受体、抗病小体、激素、组织协调、微生物组与抗病应用。重要结论同时解释“发生了什么”“为什么这样解释”以及“在哪些范围内成立”。

**第一次阅读，建议从[学习路线与知识地图](learning/学习路线与知识地图.md)开始；需要补基础时，直接进入[第 0 章](learning/ch00-细胞与分子基础.md)。**

## 怎样建立理解

每章围绕科学问题组织内容，配有学习目标、概念衔接和带讲解的自测题。机制图呈现空间与因果关系，比较表辨析容易混淆的概念，里程碑研究展示知识如何形成与修正。不必一开始就记住所有分子名称；先理解它们承担的角色，再补充细节。

全书强调三个区别：感知到信号，不等于完成保护；一个指标改变，不等于整套免疫都改变；在一个模型中成立，不等于能直接推广到所有植物。学会这些区别，可以帮助你独立阅读论文。

## 怎样使用本版

本版在原有 16 章基础上增加基础导论与 4 个专题，形成 **21 章**的教材结构，补充逐章学习支持与关键科学校订。实验方法部分侧重测量对象、推理用途和局限，帮助读者读懂证据。

这是持续修订的学习书稿。关键修订与新增研究给出来源；旧稿的全部引文和转载图尚未完成逐项出版审核。[版本说明与证据边界](appendix/版本说明与证据边界.md)记录本次工作的范围与仍需复核之处。阅读前沿内容时，应把特定体系中的研究发现与已经广泛支持的基础知识区分开。

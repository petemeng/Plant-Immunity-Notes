# ch01 植物免疫全景

## 1. 引言（这个领域在回答什么核心科学问题？）

植物没有类似脊椎动物的适应性免疫系统，但仍能在复杂环境中长期存活。  
这个领域的核心科学问题是：

- 植物如何在早期、快速地区分“危险信号”与“背景噪声”？
- 细胞表面受体与细胞内受体如何协同，而不是各自为战？
- 相同的下游反应（ROS、MAPK、转录重编程）如何被不同病原情境“编码”成不同抗病结果？

!!! note "本章主线"
    先建立全景图：输入层（危险感知） -> 信号层（网络放大） -> 输出层（抗病表型）。

## 2. 认知演变（过去怎么认为 -> 关键突破 -> 现在怎么理解）

| 阶段 | 当时主流认知 | 关键突破 | 现在的修正理解 |
|---|---|---|---|
| 早期基因对基因阶段 | 抗病主要由单个 R 基因决定 | 病原效应子与宿主识别关系逐步清晰 | 单基因解释不够，必须放入网络背景 |
| 二层模型阶段 | PTI 与 ETI 是两条相对分离通路 | `The Plant Immune System`（Jones & Dangl, 2006）提出整合框架 | 二层框架仍有效，但“分离”被弱化 |
| 机制深化阶段 | PTI 负责表面识别，ETI 负责强反应 | FLS2-BAK1 复合体、RBOHD/BIK1、抗病小体等机制被解析 | 二者共享大量核心节点 |
| 网络重塑阶段 | PTI 和 ETI 可独立完成抗病 | 2021 两篇 Nature（Ngou; Yuan） | 主流转向“互相增强（mutual potentiation）”模型 |

过去常见误解是：`PTI=弱`、`ETI=强`、`两者各干各的`。  
现在更准确的说法是：两者触发机制不同，但抗病输出在网络层深度耦合。

## 3. 核心机制（分子层面的详细解析）

### 3.1 输入层：危险识别

- 细胞表面模式触发免疫 (Pattern-Triggered Immunity, PTI)：PRR 识别 MAMP/DAMP
- 细胞内效应子触发免疫 (Effector-Triggered Immunity, ETI)：NLR 识别效应子或其扰动

### 3.2 信号层：共享放大网络

两个系统都可汇入以下关键模块：

- 受体复合体与早期磷酸化网络（如 BAK1、BIK1）
- 活性氧 (Reactive Oxygen Species, ROS) 爆发（核心执行者 RBOHD）
- MAPK 级联与转录重编程
- 免疫激素网络（尤其是 SA 的放大作用）

### 3.3 输出层：抗病“执行面”

- 局部抑菌与细胞壁加固（如 Callose 沉积）
- 细胞死亡相关反应（HR）与病原限制
- 防御基因表达与系统层免疫准备（如 SAR）

### 3.4 一个实用判断

如果一个结论只停留在“分子事件变化”，还不能算“免疫机制成立”。  
至少要补上病原增殖或抗病表型证据，才能形成闭环。

## 4. 里程碑研究（思路拆解：作者怎么想到的？逻辑链怎么搭的？）

### 里程碑 1：Jones & Dangl, 2006（框架整合）

- 科学动机：当时大量“局部机制”互相割裂，缺统一解释
- 关键思路：用二层模型把“模式识别”和“效应子识别”纳入同一逻辑
- 影响：为后续 15+ 年实验设计提供了公共语言

### 里程碑 2：Zipfel et al., 2006 + Chinchilla et al., 2007（PTI 受体机制）

- 科学动机：PTI 是否有可定义的“受体-共受体”分子事件？
- 关键策略：从配体（flg22/EF-Tu）切入，追踪受体复合体形成与下游信号
- 逻辑链：`配体识别 -> 受体复合体组装 -> 早期信号激活 -> 抗病贡献`

### 里程碑 3：Wang et al., 2019（ETI 结构突破）

- 科学动机：NLR 激活长期停留在遗传学层面，缺直接结构证据
- 关键策略：重构活性复合体并用冷冻电镜解析
- 影响：把“ETI 如何被触发”从概念推测推进到结构机制

### 里程碑 4：Ngou et al., 2021 / Yuan et al., 2021（关系重塑）

- 科学动机：PTI 与 ETI 是否真的互不依赖？
- 关键策略：通过遗传背景与诱导系统“拆开再组合”两条通路
- 结论：单独激活一条通路往往不够，强免疫依赖协同放大

## 5. 当前争论与未解问题

1. `PTI/ETI` 作为术语是否仍应二元使用？  
问题不在术语本身，而在是否把它误解为“完全独立通路”。

2. 协同机制在不同病原类型中是否等价？  
细菌系统证据强，但在真菌/卵菌/病毒体系中的普适性仍在推进。

3. 免疫强度与生长代价如何精确权衡？  
实验室抗性增强不必然等于田间稳定增产。

4. 关键节点是“普适核心”还是“物种特异”？  
跨物种转化时，常见失败点正是网络背景差异而非单基因本身。

## 6. 关键实验方法 Box（研究这个方向的标准证据链）

!!! tip "标准证据链（最小闭环）"
    **第一层：触发证据**  
    PAMP/效应子处理后，早期信号（ROS、MAPK、marker genes）是否按预期变化。  
    **第二层：因果证据**  
    关键基因的缺失/互补是否改变该信号与抗病输出。  
    **第三层：功能证据**  
    病原增殖曲线、病斑或宿主损伤指标是否与机制预测一致。  
    **第四层：边界证据**  
    换病原、换遗传背景、换环境条件后结论是否仍成立。

常用组合：

- 受体层：突变体 + 配体处理 + 互作检测
- 信号层：时间梯度检测 ROS/MAPK
- 输出层：细菌生长曲线、Callose、HR/电解质渗漏

# 原图来源与使用说明

本篇直接收录 **10张已发表论文原图，来自8篇研究**。图片保留出版版本的完整面板、字母、坐标、比例尺和作者展示的数值；正文中的中文解释放在图外，未重绘条带、未裁切拼接，也未改变图像内容。

这些图片是作者发表的结果图，不等同于仪器原始输出或完整未裁剪实验记录。样本量、误差条和统计符号按相应图例解读；原文未说明或存在不一致的地方，案例中明确指出。

每张图核对了论文、原图、图例及许可声明。转载采用原文声明的Creative Commons Attribution（CC BY）许可；较早论文没有写明版本号时，照实注明，并链接原文声明及期刊许可页。各图未见另列的第三方版权排除。图下的中文讲解属于本书，不代表原作者对本书解读的认可。

## 经典论文的原站导读

第21章还讨论Chinchilla等（2007）的FLS2—BAK1发现，第23章讨论2000年与2006年的FLS2研究。相应案例提供原出版社图页或论文入口。没有将后续开放论文的图片标作这些早期研究的原图，也没有因论文可以在线阅读就默认允许复制图片。

本页的10张图有单独的来源记录，其许可不覆盖本书其他章节的旧稿图片。再次使用时，请保留对应原作者、论文和许可署名；具体权利按原文所链接的许可判断。

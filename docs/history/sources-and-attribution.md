# 怎样判断研究历史、证据与贡献归属

研究史容易写成两种不够准确的样子：一份缺少解释的论文年表，或一段好像所有发现都早有计划的成功故事。本系列选择另一种写法：按照公开证据重建问题之间的联系，保留当时的不确定性，说明后续研究改变了什么。

## 先区分五种不同的“发现”

| 层次 | 它实际回答什么 | 不能直接替代什么 |
|---|---|---|
| 表型与遗传位点 | 某种可遗传差异与性状有关 | 尚未确定具体基因、蛋白或作用方式 |
| 基因克隆与身份确定 | 哪个基因对应研究中的功能差异 | 不能仅凭结构域认定直接识别或催化机制 |
| 遗传功能与相互依赖 | 某组分在给定背景下是否必要，组分关系如何 | 不自动证明蛋白之间直接接触 |
| 生化、定位与结构 | 分子如何结合、催化、组装或分布 | 不自动代表完整植物中的全部功能 |
| 生理与生态意义 | 对组织、整株或群落产生什么后果 | 不自动保证跨物种、跨环境和田间条件都适用 |

例如，[ZAR1研究史](genes/ZAR1.md)把2019年的抗病小体结构与2021年的通道功能分开；这两个时间点解决的问题不同。[FLS2研究史](genes/FLS2.md)则把响应缺陷、受体身份、结合证据和复合体结构分开。如此才能知道一个经典模型究竟由哪些证据支撑。

## 年份怎样核对

优先使用出版社论文页与PubMed记录，遇到在线发表和卷期年份不同，说明采用哪一个时间。DOI字符串里出现某个年份，并不等于论文就发表于那个年份。实验室简介或新闻能提供线索，但年份、题名和作者仍应回到原始记录核对。

年表中的年份指论文公开的节点，通常不能证明实验首次完成的日期，更不能证明某个想法第一次在组内出现的日期。这里不依据发表顺序编写未公开的个人动机或竞争故事。

近期论文同样需要判断证据范围。本版在[NPR1篇](genes/NPR1.md)收录2026年9月的明确发表节点，但不因为它新就把所有旧模型一笔抹去。另一些页面集中在较早的奠基阶段，其截止年份不代表团队在此后停止研究。

## 怎样处理旧模型与新证据的冲突

先问新研究挑战的是哪一个命题，再问它是否提供了更能区分替代解释的证据。[Pi-ta篇](genes/Pi-ta.md)适合练习：早期直接结合模型与2024年Ptr相关识别证据之间存在实质性的解释变化，不能为了让叙事平滑而写成两个结论无条件兼容。

[XA21篇](genes/XA21.md)则区分历史上被撤回的Ax21配体论断与后来RaxX研究。撤稿记录必须作为文献状态的一部分呈现；它不能因为已经出现在很多旧综述里，就继续作为正常证据引用。另一方面，某条配体解释被撤回，不等于XA21早期遗传与受体身份的所有证据都被否定。

模型修订也可能是范围细化。[MPK3/MPK6篇](genes/MPK3-MPK6.md)说明，早期级联简图需要与后来不同支路的证据区分；[NPR1篇](genes/NPR1.md)说明，蛋白状态的解释需要考虑样品处理、实验条件与后续结构约束。专业阅读的目标是确定哪里改变，避免只给论文贴上“正确”或“错误”的整体标签。

## 课题组不是单人作者，也不是固定机构

页面使用负责人姓名作为检索入口，不能据此把第一作者、共同作者和合作团队的贡献全部吸收到一个名字之下。经典论文常跨多个实验室，同一工作在多个团队页面出现，是不同视角下的共同节点。

早期求学或博士后时期的论文，可以作为研究者科学问题形成的背景，却不能改写成后来独立课题组的成果。团队迁移也需要区分论文当时的单位与现在的单位。对退休或荣休研究者，若官方资料明确说明，本系列尽量注明，避免把历史研究介绍当作当前实验室招募信息。

共同署名能够支持合作关系，却不足以单独证明导师谱系、贡献比例或私人关系。没有清晰来源时，本书不画推测性的师承图，不依据作者顺序编造谁首先想到某个问题。

## 名称和大小写为什么值得注意

| 名称类型 | 本系列中的例子 | 阅读提醒 |
|---|---|---|
| 单一经典基因 | FLS2、NPR1、ZAR1 | 基因与蛋白在行文中按讨论层次区分 |
| 成对或协作模块 | Pto/Prf、RPS4/RRS1 | 同页不表示同一蛋白或完全相同的功能 |
| 多成员家族 | ADR1与NRG1 | 某成员证据不能不加说明推广到所有成员 |
| 代谢与转运模块 | ICS1/EDS5/PBS3 | 多步骤关系不等于每个蛋白都执行同一种反应 |
| 历史位点与分子身份 | Pi-ta、Ptr | 不同年代的名称可能指向不同层级，需读上下文 |

为便于检索，目录采用常见符号；正文涉及物种、同源成员与等位差异时应保留限定。例如番茄FLS3不能等同于拟南芥中已建立的一套同名机制，作物Ptr1也不能仅凭名称与水稻Ptr混为一谈。

## 本版来源的使用范围

科学机制优先引用原始研究，团队机构信息优先引用大学、研究所或实验室官网。综述用于概念定位时明确其性质，不把综述发表时间写成某个发现的首次时间。每篇的核心历史节点给出可追溯入口，正文解释保持在可核验摘要、正文或公开图文支持的范围内。

本版没有重新分析所有原始数据，也没有声称逐篇完成同行评审。原有教材中转载图片与全部旧引文的出版级审核范围，见[版本说明](../appendix/版本说明与证据边界.md)。新增研究史主要采用原创文字、对照表和教学图，不用论文图片代替机制解释。

## 一页论文卡片

| 项目 | 记录内容 |
|---|---|
| 身份 | 题名、作者、年份、期刊、DOI或PubMed链接 |
| 当时的问题 | 论文试图区分什么解释？ |
| 直接观察 | 不加推论地描述主要读出 |
| 关键比较 | 哪个对照或独立证据使结论成立？ |
| 结论层次 | 关联、必要性、充分性、直接机制或生理意义 |
| 限制 | 物种、组织、条件、材料和未排除的解释 |
| 历史位置 | 它保留、扩展还是修订了先前模型？ |
| 后续入口 | 下一篇论文如何处理仍未解决的问题？ |

# 免疫与微生物：植物怎样在有微生物的世界里维持健康

植物免疫不仅关系到病原侵害后的防御，也关系到一株植物怎样与周围微生物持续共处。根际和叶片中的成员会影响资源、组织状态与彼此的生存条件；其中有些关系形成专门的共生结构，有些带来保护，有些只在特定环境下产生收益。要理解这些联系，需要把分子机制放回组织和群落之中。

本篇在[第10章微生物组全景](../part4-交叉前沿/ch10-植物微生物组与免疫.md)、[第18章系统免疫](../part6-专题与研读/ch18-系统免疫与防御预激.md)和[第19章根部免疫](../part6-专题与研读/ch19-根部免疫与共生边界.md)的基础上，展开四个层次：**宿主怎样影响群落，共生怎样协调识别与交换，保护收益经过什么过程，以及研究证据允许我们怎样解释。**

## 先把容易混淆的词分开

这些词经常出现在同一篇论文中，却不是同一层次的描述。下表约定本篇的主要用法；更具体的范围见各章及[术语表](../appendix/术语表.md)。

| 术语 | 在本篇中的含义 | 不能仅凭它推出什么 |
|---|---|---|
| 微生物群落 microbiota | 特定环境中微生物成员的集合 | 不等于已经知道每个成员的功能 |
| 微生物组 microbiome | 本篇指这些成员及其遗传和功能信息；不同文献范围可能更广 | 不能把一份标记序列清单当作全部生态过程 |
| 定殖 colonization | 在某处建立并维持存在 | 不自动表示致病、互利或宿主净收益 |
| 共栖 commensal association | 本篇常用于没有明显病害表现的宿主相关共处；严格生态定义更强调一方获益而另一方无明显影响 | 未测到损伤不等于已经证明对双方都无影响 |
| 互利 mutualism | 在所讨论背景中双方获得收益 | 不能假定换一种营养或环境背景仍保持相同净收益 |
| 菌群失衡 dysbiosis | 与宿主健康或功能异常相联系的群落状态改变 | 组成不同、某类群富集或多样性降低本身还不够 |
| 诱导系统抗性 ISR | 局部微生物互作引出的宿主远端保护 | 不等于微生物对病原的直接抑制，也没有单一通用激素模式 |
| 预激 priming | 先前经历改变后续响应能力 | 不要求所有防御基因在挑战前持续高表达 |
| 相对丰度 relative abundance | 某类信号占所测总信号的比例 | 不独自给出该成员的绝对数量、活细胞数或活性 |

学习时可始终保留三栏笔记：**微生物发生了什么变化、宿主发生了什么变化、什么证据把两者联系起来。** 如果第三栏只有“同时出现”，就应继续寻找时间关系、功能比较和替代解释。这也是第27章贯穿的阅读方法。

## 按你的基础选择读法

初学者先读第19章，再按24→25→26→27阅读。第一遍关注空间、过程和结果；第二遍再学习受体名称、核钙模块与宿主转录调控。遇到生物学缩写时，先把它翻译成角色，例如“识别组件”“细胞内信号译码器”或“营养交换界面”，再回到具体名称。

已经熟悉PTI、ETI和激素的读者，可以先进入第24章与第26章，比较群落稳态和诱导保护。若主要想读微生物组论文，先读第27章的测量与数量部分，再用第24章提供的宿主实例校验自己的理解；不能只学测序术语而跳过植物结局。

准备讨论生防应用时，在第26章之后衔接[第15章](../part5-转化与展望/ch15-微生物组工程与生物防治.md)。重点是解释某项结果在哪个宿主、土壤和环境中成立，以及从模型推向应用还缺少什么支持。

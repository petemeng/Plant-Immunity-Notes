# 跨主题发现年表：问题怎样从基因身份走向免疫网络

这张年表选取本系列已经讨论的代表节点，帮助读者比较不同分支的发展。它不是全领域优先权榜单，也不是按年代排列的完整文献数据库。每一行链接到相应研究史，原始论文、作者与适用范围在那里展开。

## 将年代转换成研究理解

任选一行，分别写下“此前已知”“此次新增”“尚未证明”。例如，看到2019年ZAR1复合体结构，不能把2021年通道功能的证据提前放进2019年；看到2024年Pi-ta解释修订，也不能说早期抗性品种的观察因此从未成立。

再横向比较两个主题：FLS2和NPR1都经历了从遗传学到结构的推进，但一个围绕细胞表面感知，一个围绕转录调控，不能因方法相似就假定机制相同。研究史的价值正是在相似推理方式中看到不同生物学问题。

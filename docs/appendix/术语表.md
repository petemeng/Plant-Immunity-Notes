# 术语表

本表供随读随查，不要求一次背完。先分清“分子是什么”“实验看见了什么”和“据此能得出什么结论”。基因、蛋白、细胞类型和细胞状态不是同一层次的概念；括号中的英文缩写也可能因文献领域不同而重名。

零基础可先读[细胞与分子基础](../learning/ch00-细胞与分子基础.md)。结构防御、系统免疫和根部免疫分别见[第17章](../part6-专题与研读/ch17-屏障与化学防御.md)、[第18章](../part6-专题与研读/ch18-系统免疫与防御预激.md)和[第19章](../part6-专题与研读/ch19-根部免疫与共生边界.md)。本表定义是教学概括；具体机制须回到物种、组织和证据条件。

## 核心免疫概念

| 中文术语 | 英文 | 简要定义 |
|----------|------|----------|
| 模式触发免疫 | Pattern-Triggered Immunity (PTI) | 由细胞表面模式识别受体感知相关分子模式而启动的免疫；与 ETI 可互相增强，并非固定时间顺序中的独立第一道关卡 |
| 效应子触发免疫 | Effector-Triggered Immunity (ETI) | 由效应子或其对宿主造成的变化被识别后启动的免疫，经典体系主要涉及细胞内 NLR；不以可见细胞死亡为必要定义 |
| 效应子触发感病性 | Effector-Triggered Susceptibility (ETS) | 效应子活动使宿主更有利于病原定殖的概念性描述；不应当作所有易感互作必有的独立细胞类型或固定阶段 |
| 系统性获得抗性 | Systemic Acquired Resistance (SAR) | 局部病原相关刺激后远端组织形成的增强抗性；经典体系与 SA、NHP 等网络有关，广度、持续性与组织范围依情境而变 |
| 诱导系统抗性 | Induced Systemic Resistance (ISR) | 常指有益微生物等诱导的远端保护；部分经典体系依赖 JA/ET 响应能力，不能推广为所有 ISR 都不涉及 SA |
| 超敏反应 | Hypersensitive Response (HR) | 免疫激活相关的局部细胞死亡现象；与抗性可相关但并不等同，细胞死亡本身不能证明成功限制病原 |
| 非宿主抗性 | Non-host Resistance | 通常指一个植物物种对能够侵染其他植物物种的某病原群体表现出的抗性；实际判断受所测试基因型、分离物和环境范围限制 |
| 基础抗性 | Basal Resistance | 特定互作中宿主限制病原的基础防御能力，可由多类组分贡献；不宜机械等同于 PTI 或断言与 NLR 完全无关 |
| 防御预激 | Defense / Immune Priming | 先前经历使后续防御反应的速度、幅度或性质改变；刺激前可已有部分分子变化，应与持续高表达分开判断 |
| 免疫记忆 | Immune Memory | 先前经历在一定时间后仍影响防御的功能性说法，不意味着动物式抗体记忆或主观回忆 |
| 跨代免疫记忆 | Transgenerational Immune Memory | 防御相关经验效应在后代延续的研究概念；需明确世代，并排除直接暴露、种子携带、母体营养与选择效应，不能默认已证明表观遗传机制 |
| 抗性 | Resistance | 限制病原定殖、增殖或负荷的宿主能力；症状轻重不能单独代表病原负荷 |
| 耐受性 | Tolerance | 在一定病原负荷下维持生长、繁殖或减少损失的能力；不要求病原数量一定下降 |

## 受体与识别

| 中文术语 | 英文 | 简要定义 |
|----------|------|----------|
| 模式识别受体 | Pattern Recognition Receptor (PRR) | 定位于质膜的受体蛋白，识别保守的微生物分子模式（MAMP/PAMP）或宿主损伤信号（DAMP） |
| 核苷酸结合富亮氨酸重复受体 | Nucleotide-binding Leucine-rich Repeat receptor (NLR) | 细胞内免疫受体，直接或间接识别病原效应蛋白，激活 ETI |
| 受体样激酶 | Receptor-Like Kinase (RLK) | 含胞外配体结合域和胞内激酶域的跨膜受体蛋白 |
| 受体样蛋白 | Receptor-Like Protein (RLP) | 含胞外配体结合域但缺乏胞内激酶域的跨膜受体蛋白，需要与 RLK 共受体配合 |
| 受体样胞质激酶 | Receptor-Like Cytoplasmic Kinase (RLCK) | 缺乏胞外域的胞内激酶，与 PRR 复合体结合并传递早期免疫信号 |
| CC-NLR | CC-NLR (CNL) | 具有典型卷曲螺旋 N 端结构域的一类 NLR；部分成员形成具有离子通透功能的复合体，不能把一种已解析结构推广到全部成员 |
| TIR-NLR | TIR-NLR (TNL) | 具有 TIR 结构域的一类 NLR；代表体系中其酶活性产生核苷酸衍生信号，连接 EDS1 相关模块与辅助 NLR |
| RPW8 样 NLR | RPW8-like NLR (RNL) | 具有 RPW8 样 CC<sub>R</sub> 结构域的 NLR 类群，包括 ADR1、NRG1 类辅助受体；辅助 NLR 不全是 RNL，例如 NRC 属于 CNL 类群 |
| 辅助 NLR | Helper NLR | 在免疫受体网络中参与下游信号执行的功能类别，不等同于一种结构分类；其依赖关系随植物谱系和受体组合而变 |
| 抗病小体 | Resistosome | 激活后形成的 NLR 功能复合体；不同受体的亚基数与功能可能不同，如已解析的 ZAR1 五聚体，不预设所有复合体都同构 |
| 共受体 | Co-receptor | 与其他受体共同组成信号复合体的受体组分；配对、动态与必要性需按体系判断，不能假设所有 PRR 都共享 BAK1 |
| 微生物相关分子模式 | Microbe-Associated Molecular Pattern (MAMP) | 微生物中保守的、可被宿主 PRR 识别的分子（如鞭毛蛋白 flg22、EF-Tu elf18、几丁质、肽聚糖） |
| 损伤相关分子模式 | Damage-Associated Molecular Pattern (DAMP) | 宿主细胞损伤后释放的内源性分子，被 PRR 识别并触发免疫（如细胞壁碎片、ATP、HMGB3） |
| 病原相关分子模式 | Pathogen-Associated Molecular Pattern (PAMP) | 与 MAMP 概念高度重叠，强调来源于病原的特征分子 |

## 信号转导

| 中文术语 | 英文 | 简要定义 |
|----------|------|----------|
| 丝裂原活化蛋白激酶 | Mitogen-Activated Protein Kinase (MAPK) | 三层级联（MAPKKK→MAPKK→MAPK）的信号放大系统，PTI 和 ETI 的核心信号通路 |
| 活性氧爆发 | ROS Burst | 一定时间内 ROS 产生明显增强的现象，免疫中可涉及 RBOHD 等组分；来源、化学种类、区室和清除能力决定信号与损伤意义 |
| 钙离子内流 | Ca²⁺ Influx | PRR 和 NLR 激活后胞质 Ca²⁺ 浓度快速升高，通过钙传感器（CaM、CDPK、CBL-CIPK）解码为特异性免疫输出 |
| 钙依赖蛋白激酶 | Calcium-Dependent Protein Kinase (CDPK) | 直接结合 Ca²⁺ 的蛋白激酶，将 Ca²⁺ 信号转化为蛋白磷酸化输出 |
| 呼吸爆发氧化酶同源蛋白 D | Respiratory Burst Oxidase Homolog D (RBOHD) | 质膜 NADPH 氧化酶，是 PTI 和 ETI 中 ROS 爆发的主要来源 |
| BRI1 相关受体激酶 1 | BRI1-Associated Receptor Kinase 1 (BAK1) | 多种 PRR 的共受体，同时也是 brassinosteroid 受体的共受体——连接免疫与生长信号的核心节点 |
| Botrytis-Induced Kinase 1 | BIK1 | 与 PRR 复合体结合的 RLCK，PRR 激活后被 BAK1 磷酸化并释放，磷酸化下游底物激活免疫 |
| 水杨酸 | Salicylic Acid (SA) | 参与防御、系统性抗性与其他生理过程的激素；其保护作用受组织、时间和互作对象影响 |
| 茉莉酸 | Jasmonic Acid (JA) | 参与伤害、部分病害和植食性动物响应及发育的激素；JA-Ile 是经典 COI1–JAZ 感知系统的重要活性形式 |
| 乙烯 | Ethylene (ET) | 调节发育、衰老和防御的气体激素，可与 JA 等信号协同或发生情境依赖的互作 |
| 脱落酸 | Abscisic Acid (ABA) | 参与水分、种子与其他生理过程的激素，在不同组织和阶段可促进或限制不同免疫输出 |
| NPR1 | Non-expressor of pathogenesis-related genes 1 | SA 相关防御的重要转录共调控蛋白，与 TGA、转录介体等组分合作；构象与复合体组装很重要，不能只用经典“寡聚体变单体”模型概括 |
| 冠菌素 | Coronatine (COR) | *P. syringae* 产生的 JA-Ile 结构类似物，劫持 JA 通路来拮抗 SA 防御 |
| 气孔免疫 | Stomatal Immunity | 保卫细胞响应免疫线索而调节气孔状态，影响组织入口处的保护；气孔也受水分、光照等调控，关闭不等于已经证明抗病 |

## NLR 与效应子

| 中文术语 | 英文 | 简要定义 |
|----------|------|----------|
| 效应子 | Effector | 在互作中改变宿主结构或生理过程的微生物分子，常为分泌蛋白；其影响依宿主背景而异，既可能促进定殖，也可能被识别 |
| III 型分泌系统 | Type III Secretion System (T3SS) | 革兰氏阴性细菌用于将效应蛋白直接注射到宿主细胞内的分子装置 |
| 无毒基因 | Avirulence (Avr) Gene | 在具有相应识别能力的宿主背景中使微生物表现出无毒性或抗性互作的基因；“无毒”不是对所有宿主的绝对属性 |
| 抗性基因 | Resistance (R) Gene | 遗传学上与抗性相关的宿主基因，产物可包括 NLR、细胞表面受体等，并非全部都是 NLR |
| 基因对基因假说 | Gene-for-Gene Hypothesis | Flor 提出的假说：宿主抗性取决于宿主 R 基因与病原 Avr 基因的特异性配对 |
| Guard 模型 | Guard Model | NLR "守护"效应蛋白的宿主毒力靶标，通过感知靶标被效应蛋白修饰来间接识别病原 |
| 诱饵模型 | Decoy Model | 某宿主组分模拟效应子的作用对象，并把识别事件连接到免疫；是否还承担其他功能须单独验证 |
| 整合结构域 / 整合诱饵模型 | Integrated Domain / Integrated Decoy Model | NLR 融合的附加结构域可参与效应子识别；“整合结构域”是结构描述，“诱饵”则是需要功能和进化证据的解释 |
| 枢纽收敛 | Hub Convergence | 不同进化起源的效应蛋白反复靶向同一组高连通度的宿主枢纽蛋白的现象 |
| 最小效应子集合 | Minimal Effector Repertoire | 在限定宿主、环境和评价标准下讨论的功能集合概念，不是脱离实验条件的固定清单 |
| RNA 沉默抑制子 | Viral Suppressor of RNA Silencing (VSR) | 某些病毒编码的、干扰宿主 RNA 沉默的蛋白；不能把已研究代表的机制等同于所有病毒 |
| 跨界 RNA 干扰 | Cross-Kingdom RNAi | 一种生物来源的 RNA 影响另一生物的序列相关沉默；发生方向、运输路径和生理贡献需分别证明 |

## 激素与信号网络

| 中文术语 | 英文 | 简要定义 |
|----------|------|----------|
| SA-JA 拮抗 | SA-JA Antagonism | 特定条件下两类信号或其输出相互抑制；不是永恒的二选一开关，亦可存在协同和分支差异 |
| 激素串扰 | Hormone Crosstalk | 不同激素信号通路之间的相互调控（协同、拮抗或调控），形成复杂的信号输出网络 |
| SAR 移动信号 | SAR Mobile Signal | 参与局部与远端防御协调的可移动分子；必须区分移动性、信号生成、接收与放大，不能把所有相关组分都称作运输中的信号 |
| 哌啶酸 | Pipecolic Acid (Pip) | 与赖氨酸代谢有关的非蛋白氨基酸，在经典体系中与 NHP 形成及系统免疫相联系；Pip 与 NHP 不是同一种分子 |
| N-羟基哌啶酸 | N-Hydroxypipecolic Acid (NHP) | 与 FMO1 功能相关的代谢物，参与系统性抗性、转录重编程与预激；与 SA 形成相互联系的网络，不能简单固定为 SA 下游 |
| 甘油-3-磷酸 | Glycerol-3-phosphate (G3P) | 与脂质代谢及某些系统免疫过程相关；本书 SAR 语境的 G3P 指此分子，不是甘油醛-3-磷酸 |
| 甘油醛-3-磷酸 | Glyceraldehyde-3-phosphate (GAP) | 糖代谢中的三碳磷酸化合物；有些文献也写 G3P，因此必须用英文全称核对 |
| 生长素 | Auxin | 调节生长发育的激素类群，也影响免疫与微生物互作；其结果不能概括为一律促感病 |

## 微生物组

| 中文术语 | 英文 | 简要定义 |
|----------|------|----------|
| 根际 | Rhizosphere | 受到根的生长、分泌和吸收活动影响的周围土壤区域，与根表和根内部应区分 |
| 根表 | Rhizoplane | 根与外部环境接触的表面，研究中需明确实际采样定义 |
| 内生空间 / 根内空间 | Endosphere | 植物组织内部的微生物栖息空间；广义 endosphere 不只限于根 |
| 叶际 | Phyllosphere | 通常指以叶片为主的地上器官相关微生物环境，常侧重表面；若包括内生部分，应明确采样范围 |
| 两步筛选模型 | Two-Step Selection Model | 概括从土壤到根相关空间的群落筛选；实际组装还受扩散、环境、微生物互作和随机过程影响，不只有免疫筛选 |
| 合成群落 | Synthetic Community (SynCom) | 由已知成员组成、用于因果研究的人工定义群落；成员数可以很多，不必是“最小群落” |
| 抑病性土壤 | Disease-Suppressive Soil | 具备天然抑制特定土传病害能力的土壤，其抑病性通常由特定微生物群落介导 |
| 菌群失调 | Dysbiosis | 与宿主功能异常相联系的群落状态改变；单纯多样性或组成不同不能自动称为失调 |
| 呼救假说 | Cry for Help Hypothesis | 植物受胁迫后改变根际环境，促进有保护作用的微生物参与互作的解释；需证明招募与功能联系，不必涉及后代 |
| 土壤遗产 / 土壤记忆 | Soil Legacy / Soil Memory | 先前植物或环境对后续土壤状态和植物表现的持续影响，可包括生物与非生物因素，不等于植物遗传记忆 |
| ISR 诱导微生物 | ISR-Eliciting Microbe | 在明确的植物和环境条件下能够诱导远端保护的微生物；“有益”与“诱导 ISR”需要相应证据 |

### 共生识别与交换

配合[第25章](../part8-免疫与微生物/ch25-共生识别与免疫协调.md)阅读，先区分识别、细胞内信号、交换界面和实际收益。

| 中文术语 | 英文或缩写 | 简要定义 |
|---|---|---|
| 丛枝菌根 | Arbuscular mycorrhiza, AM | 植物根与相应真菌形成的共生；丛枝是重要交换界面，不能由定殖量直接推断净收益 |
| 脂壳寡糖 | Lipochitooligosaccharide, LCO | 具有脂质修饰的几丁质相关寡糖；骨架之外的修饰也影响识别 |
| Nod因子 | Nod factor / Nod-LCO | 典型根瘤共生识别中的细菌信号；识别依赖相应宿主受体和背景 |
| Myc-LCO | Mycorrhizal LCO | 与丛枝菌根相关的一类信号；不能据其作用推断它是所有AM互作的唯一输入 |
| 共同共生信号通路 | Common symbiosis signaling pathway, CSSP | 根瘤与AM共生共享的宿主信号模块，包含核内/核周钙振荡及其译码；不是所有共栖的通用路径 |
| 钙与钙调蛋白依赖蛋白激酶 | CCaMK | 将共生相关钙信号连接到下游程序的宿主激酶，不等于全部钙信号的统一读出 |
| 共生体 | Symbiosome | 根瘤细胞中由宿主来源膜包围的细菌共生单元，内部伙伴保留自身边界 |
| 共生体膜 | Symbiosome membrane | 包围根瘤共生单元的宿主来源膜，参与界面组织与交换 |
| 丛枝周膜 | Periarbuscular membrane | 围绕丛枝形成的宿主来源膜；它与真菌自身边界之间存在界面空间 |
| 共生制裁 | Host sanctions | 宿主对收益不足伙伴的差异化资源投入或限制；具体机制和作用层次依体系而异 |

### 群落测量与因果

配合[第27章](../part8-免疫与微生物/ch27-微生物组研究的证据与因果.md)阅读；“菌群失衡”与上表“菌群失调”对应同一英文词dysbiosis。

| 中文术语 | 英文或缩写 | 简要定义 |
|---|---|---|
| 微生物群落 | Microbiota | 特定环境中的微生物成员集合 |
| 微生物组 | Microbiome | 本篇指群落成员及其遗传和功能信息；其他文献可能采用更广的生态环境定义 |
| 扩增子序列变体 | Amplicon sequence variant, ASV | 依据标记区段推断的序列变体，不自动等于一个物种或菌株 |
| 相对丰度 | Relative abundance | 某类所测信号占总信号的比例，变化受其他类群和分母共同影响 |
| 数量尺度 | Quantitative abundance scale | 为群落信号加入明确的参照单位；不同尺度的含义应分别解释 |
| 宿主关联定量丰度分析 | HA-QAP | 将微生物标记拷贝与宿主基因组参照联系的定量框架；比值不是直接的活细胞计数 |
| 核心微生物群落 | Core microbiota | 在研究定义的范围内较稳定出现的成员集合；核心成员不自动等于功能上不可替代的成员 |
| 优先效应 | Priority effects | 成员出现的先后历史影响后续群落组装；具体结果依成员及环境背景而变 |
| 群落关键成员 | Keystone member | 对某项群落结果产生较大影响的成员；结构关键性不自动意味着免疫保护关键性 |
| 功能冗余 | Functional redundancy | 不同成员能够承担部分相似功能；不表示所有生态位置和宿主效应可以互换 |
| α多样性 | Alpha diversity | 样本内部多样程度，具体含义取决于丰富度、均匀度等指标 |
| β多样性 | Beta diversity | 样本之间群落差异的量度；排序分离本身不证明宿主健康或免疫功能不同 |
| 组成型数据 | Compositional data | 以整体中各部分比例表示的数据，解释需考虑总和约束 |

## RNA 生物学

| 中文术语 | 英文 | 简要定义 |
|----------|------|----------|
| RNA 干扰 / RNA 沉默 | RNA Interference (RNAi) / RNA Silencing | 小 RNA 引导的序列特异性基因沉默机制，在植物中主要通过 mRNA 切割、翻译抑制和 DNA 甲基化实现 |
| 微 RNA | microRNA (miRNA) | 基因组编码的 ~21 nt 内源小 RNA，通过碱基互补配对靶向 mRNA 切割或翻译抑制，精密调控免疫信号蛋白的表达 |
| 小干扰 RNA | Small Interfering RNA (siRNA) | 常由双链 RNA 前体加工产生的小 RNA，植物中常见长度约21—24 nt，功能取决于来源与效应复合体 |
| 相位小干扰 RNA | Phased siRNA (phasiRNA) | 从前体按相对规则间距产生的小 RNA，可有21 nt 或24 nt等类型；具体生物发生途径不能一律限定为 DCL4 |
| 长链非编码 RNA | long non-coding RNA (lncRNA) | >200 nt 的非编码 RNA，通过染色质修饰引导、转录调控和分子支架等功能参与免疫调控 |
| RNA 指导的 DNA 甲基化 | RNA-Directed DNA Methylation (RdDM) | 植物中重要的 RNA 引导 DNA 甲基化过程，经典通路常涉及24 nt siRNA；存在不同分支，不应把所有相关过程简化为同一路径 |
| 宿主诱导基因沉默 | Host-Induced Gene Silencing (HIGS) | 在转基因植物中表达靶向病原关键基因的 dsRNA/siRNA，通过跨界 RNAi 抑制病原的毒力 |
| 喷雾诱导基因沉默 | Spray-Induced Gene Silencing (SIGS) | 直接向植物表面喷洒靶向病原基因的 dsRNA/siRNA，通过跨界 RNAi 抑制病原 |
| Dicer 样蛋白 | Dicer-Like (DCL) | RNA 酶 III 家族蛋白，将长 dsRNA 加工为特定长度的小 RNA（DCL1→21 nt miRNA, DCL4→21 nt siRNA, DCL3→24 nt siRNA） |
| Argonaute | AGO | 小 RNA 的效应蛋白，与小 RNA 组装为 RISC 复合体并通过碱基互补配对靶向 RNA 切割或翻译抑制 |

## 进化与群体遗传学

| 中文术语 | 英文 | 简要定义 |
|----------|------|----------|
| 军备竞赛模型 | Arms Race Model | 宿主和病原在持续的适应性突变中反复"攻击-防御"的协同进化动态 |
| 频率依赖选择 | Frequency-Dependent Selection | 基因型适合度取决于自身或互作方基因型频率的选择；负频率依赖可能使稀有型有利，但不能仅凭某 Avr 频率低就断言对应 R 有优势 |
| 杂种坏死 | Hybrid Necrosis | 某些杂交后代的坏死与生长异常表型，可涉及免疫基因不相容；并非所有实例都只由 NLR 导致 |
| NLR 出生-死亡进化 | NLR Birth-and-Death Evolution | NLR 基因家族通过快速重复、序列多样化、假基因化和删除进行的动态进化模式 |
| 平衡选择 | Balancing Selection | 维持群体中多种抗性等位基因多态性的自然选择形式 |
| 协同进化 | Co-evolution | 两个或多个物种在进化中相互施加选择压力导致相互适应的过程 |
| 选择性清扫 | Selective Sweep | 有利等位基因在群体中快速固定导致周围基因组区域遗传多样性降低的现象 |

## 实验技术

| 中文术语 | 英文 | 简要定义 |
|----------|------|----------|
| [酵母双杂交](../part7-研究技术与实验逻辑/ch21-蛋白质相互作用研究技术.md) | Yeast Two-Hybrid (Y2H) | 将候选蛋白关联转为酵母中的报告输出；经典系统需区分BD、AD、自激活和基本生长，结果保留异源系统范围 |
| [免疫共沉淀](../part7-研究技术与实验逻辑/ch21-蛋白质相互作用研究技术.md) | Co-Immunoprecipitation (Co-IP) | 利用抗体富集目标蛋白，检测共同富集的伙伴；支持共复合体关联，不自动证明直接结合 |
| 双分子荧光互补 | Bimolecular Fluorescence Complementation (BiFC) | 候选蛋白使荧光蛋白片段接近并产生互补信号；片段自发互补、成熟延迟及关系稳定化会影响解释 |
| [染色质免疫沉淀测序](../part7-研究技术与实验逻辑/ch22-表达定位与转录调控研究技术.md) | ChIP-seq | 富集目标蛋白或组蛋白状态相关的染色质并测序；反映DNA区域关联，不保证直接接触DNA或改变表达 |
| ATAC-seq | Assay for Transposase-Accessible Chromatin | 利用转座酶探测开放染色质区域的高通量测序技术 |
| 群体转录组 / 单细胞转录组 | Bulk RNA-seq / scRNA-seq | 分别汇总样本中的 RNA 信号或获取单细胞层面的信号；表达量不是蛋白活性，细胞数量也不等于独立植物样本数量 |
| 16S rRNA 扩增子测序 | 16S rRNA Amplicon Sequencing | 通过扩增和测序细菌 16S rRNA 基因的可变区来刻画微生物群落分类组成 |
| 空间转录组学 | Spatial Transcriptomics | 在保留组织空间结构的情况下获取基因表达信息的技术（如 Visium、MERFISH） |
| CRISPR/Cas9 | Clustered Regularly Interspaced Short Palindromic Repeats / Cas9 | RNA 引导的基因组编辑技术，广泛应用于植物免疫基因的功能验证和作物抗性工程化 |

## 其他重要概念

| 中文术语 | 英文 | 简要定义 |

| 逆行信号 | Retrograde Signaling | 从细胞器（叶绿体、线粒体）向细胞核传递的信号通路——叶绿体逆行信号将光胁迫与免疫耦合 |

|---|---|---|
| 细胞类型 | Cell Type | 根据谱系、位置、结构和稳定功能等划分的细胞身份，例如保卫细胞、叶肉细胞 |
| 细胞状态 | Cell State | 同一细胞类型在发育、环境或免疫影响下出现的可变分子与生理状态；转录聚类不自动等于新细胞类型 |
| 标记基因 | Marker Gene | 在某一类型或状态中具有判别价值的基因；表达特异性需经组织、条件与独立证据验证 |
| 相关性 | Correlation / Association | 两个变量共同变化的统计关系，不能单独证明谁导致谁 |
| 必要性 | Necessity | 在限定背景中，缺少某因素使某结果无法正常发生；不等于该因素直接执行全部过程 |
| 充分性 | Sufficiency | 在限定背景中，某因素的出现足以引出所讨论的结果；不代表自然情形只靠这一因素 |
| 遗传互作 | Genetic Interaction | 多个遗传变化的组合结果不同于简单独立预期，有助于分析功能关系，但不一定等于蛋白直接结合 |
| 互补 / 功能恢复 | Complementation / Rescue | 恢复某组分或相关功能后表型得到恢复的证据；能加强归因，但仍需考虑剂量和表达位置 |
| 生物学重复 | Biological Replicate | 独立产生、能体现所讨论生物变异的样本；同一植物的多个细胞或多次读数通常不能替代独立植物 |
| 技术重复 | Technical Replicate | 对同一生物材料重复测量，用于估计测量误差；不增加独立生物样本数 |
| 批次效应 | Batch Effect | 由采样、处理或测量批次引起的系统差异，可能被误读为生物学状态变化 |
| 伪重复 | Pseudoreplication | 把不独立的观察当成独立样本，使证据看起来比实际更强 |
| 效应量 | Effect Size | 差异或关系的大小，需结合不确定性和生物学意义，不能只看 P 值 |
| 多效性 | Pleiotropy | 同一遗传变化影响多个性状，因此表型变化不一定只来自所关注的免疫过程 |
| 通路模型 | Pathway Model | 对机制关系的可检验解释；箭头可能表示直接作用、间接依赖或工作假说，应看图例和证据 |
| 同源与功能保守 | Homology / Functional Conservation | 共同祖先来源与功能保持是不同结论；序列相似本身不能证明同样的表达位置或免疫功能 |

## 容易随研究进展改变的机制表述

- **PTI 与 ETI：**采用相互协调、可互相增强的框架，不固定为先后独立两层。参见[Ngou等，2021](https://www.nature.com/articles/s41586-021-03315-7)和[Yuan等，2021](https://www.nature.com/articles/s41586-021-03316-6)。
- **NPR1：**经典寡聚体模型不能覆盖全部活性组装状态；参见[Kumar等，2022](https://doi.org/10.1038/s41586-022-04699-w)和[Zhang等，2026](https://www.nature.com/articles/s41586-026-11021-5)。
- **HPCA1/CARD1：**受体参与氧化还原相关响应与其具体感知化学机制要分开；2026年研究对早期半胱氨酸模型作了修订，见[Ishihama等](https://www.nature.com/articles/s41467-026-72573-8)。
- **寡聚半乳糖醛酸（OG）与 WAK：**不要把“WAK 是已经确定且必需的 OG 受体”当作定义。WAK 缺失材料的新证据要求重新评估这一路径，见[原始研究记录，PMID 39665686](https://pubmed.ncbi.nlm.nih.gov/39665686/)。

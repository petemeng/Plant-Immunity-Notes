# 病理基础与侵染循环：从一次接触到下一轮传播

叶片上发现微生物，不等于已经发生感染；植物没有明显病斑，也不等于组织里没有病原。理解植物免疫，需要先知道病原在疾病过程中走到了哪里。受体识别、气孔关闭、细胞壁加固和系统免疫，分别可能影响不同环节，最终共同改变病原负担与植物损失。

**学习目标。** 读完后，你应能区分接触、侵入、感染和发病，画出侵染循环，解释初侵染与再侵染，并把一项免疫作用放回相应的病理阶段。先修内容为[第0章](ch00-细胞与分子基础.md)；本专题随后衔接[第1章](../part1-免疫骨架/ch01-植物免疫全景.md)与[拟南芥贯穿案例](拟南芥模式系统贯穿案例.md)。

## 1　疾病三角解释条件，侵染循环解释过程

**疾病三角（disease triangle）**描述感病宿主、具有致病能力的病原和适宜环境的共同作用。把三者放在一起，是为了提醒我们：一种病原能够造成疾病，要同时满足接触机会、宿主状态和环境条件。叶片年龄、组织含水状态和季节变化，又使这些条件随时间改变。

**侵染循环（disease cycle）**则追踪病原在这些条件中经历的事件，以及下一次感染从哪里开始。两张地图的用途不同：三角帮助解释为什么同一个基因型在不同环境中病害程度不同；循环帮助解释一种防御究竟影响病原进入、组织内发展还是后续传播。[植物疾病过程的教学入口](https://cropprotectionnetwork.org/web-books/crop-scouting-basics-for-corn-and-soybean?section=41-principles-of-plant-disease)

例如，气孔防御会影响一部分细菌进入叶内的机会；进入叶内之后，质外体环境与细胞防御又影响其能否增殖。直接从叶内起点观察到的抗性，并不能自动解释叶表进入这一环节。Melotto等的研究将气孔与免疫联系起来，正说明解剖位置会改变所检验的问题（Melotto et al., 2006）。[原始研究](https://doi.org/10.1016/j.cell.2006.06.054)

## 2　先学会区分六个相邻概念

| 概念 | 指什么 | 不能仅凭什么判断 |
|---|---|---|
| 接种体（inoculum） | 能引发新感染的病原单位；可为孢子、菌体或其他适宜形式 | 不同病原不能统一换算成同一种“数量” |
| 接触或接种（inoculation） | 接种体到达潜在感染部位 | 到达叶表不等于成功侵入 |
| 侵入（penetration） | 越过相应的外部组织边界 | 进入不等于建立持续感染 |
| 感染与定殖（infection and colonization） | 建立与宿主的关系，并在相应部位发展 | 暂时检出DNA不一定表示活病原持续繁殖 |
| 发病与症状（disease and symptoms） | 宿主功能或外观出现疾病相关异常 | 症状轻不一定是病原少，也可能涉及耐受 |
| 繁殖与传播（reproduction and dispersal） | 产生新的传播单位，并到达其他感染部位 | 一块病斑不能直接告诉我们下一轮传播贡献 |

这些词的具体边界随病原和研究传统有所变化。学习时把测量对象写清楚，比争论一个词是否涵盖全部阶段更有效。例如，“叶内可培养细菌负担降低”是一个明确结果；“植物全面阻止了入侵”则包含更多尚未测到的环节。

## 3　把循环画成有分支的过程

可以先写出下面这条概念顺序：

**间歇期存活或来源维持 → 接种体产生与传播 → 到达宿主 → 侵入与感染 → 定殖、宿主反应与病原繁殖 → 新的传播单位 → 新的感染。**

它不是所有病害都必须依次出现的固定剧本。某些病原在宿主残体或其他寄主上跨越不利时期；有的依赖活体组织或传播媒介维持循环。组织中存在病原、产生症状和形成传播单位也不一定同步。APS的侵染循环教学强调的是把事件及其环境条件连接起来，而非只背一圈箭头。[APS侵染循环教学](https://www.apsnet.org/edcenter/learningPP/Pages/InquiryBasedApproach.aspx)

| 阶段 | 应当追问的生物学问题 | 可以连接的免疫概念 |
|---|---|---|
| 来源与传播 | 病原从哪里来，是否接触到感病组织？ | 接触减少与宿主免疫增强要区分 |
| 表面与进入 | 能否越过角质层、气孔等边界？ | 表面屏障、气孔防御、局部模式感知 |
| 组织内建立 | 是否得到适宜空间、营养与宿主环境？ | 质外体稳态、细胞壁防御、分泌与代谢 |
| 宿主细胞反应 | 植物检测到什么，哪些输出被启动？ | PTI、ETI、激素及RNA沉默 |
| 扩展与繁殖 | 宿主是否限制病原负担与组织损失？ | 抗性与耐受、细胞死亡及修复 |
| 后续传播 | 是否产生能够引发新感染的单位？ | 局部保护与群体病害发展之间的联系 |

读论文时，不必为每个阶段都找到数据。应当明确论文实际上检验了其中哪些环节，并把尚未测量的阶段留在问题清单里。

## 4　初侵染与再侵染：一次发生和循环放大

**初侵染（primary infection）**通常指一个生长季或所定义流行周期中，由初始来源引起的感染；**再侵染或次生侵染（secondary infection）**由本周期内新产生的接种体引起。这里的“初、再”是相对于所讨论的周期，不是病原第一次出现在地球上，也不是同一片叶子的第一次和第二次检测。

当一次感染能够在同一个作物生长周期内产生新接种体，再引起新的感染，便可能形成**多循环病害（polycyclic disease）**。反之，在所定义周期内主要只有一轮感染的情形，称为**单循环病害（monocyclic disease）**。判断依据是是否重复完成感染与接种体再生产的循环，不能只数一块病斑长大了几次。[APS病害进展与循环](https://www.apsnet.org/edcenter/sites/EpidemiologyTemporal/Pages/Disease%20Progress.aspx)

这解释了为什么“单个病斑较小”和“整季病害减少”是相邻而不同的结论。病斑扩展可能减慢，但传播机会、接种体产生和新感病组织仍会影响季节性结果。反过来，一种抗性即使没有完全消灭早期感染，只要减少后续繁殖或扩展，也可能产生有意义的保护。

## 5　潜育期和潜伏期为什么不能混用

**潜育期（incubation period）**通常指感染至症状出现的间隔；流行学中的**潜伏期（latent period）**通常指感染至能够产生新接种体、进入传染性阶段的间隔。两者的终点不同，症状与传染性也不必同时出现。部分中文语境会使用不同译法，因此应同时核对英文词和作者给出的起止定义。

一张“处理后第几天的病斑照片”告诉我们某个观察时间的宿主外观，却未必告诉我们感染开始于何时、何时能够传播。论文只展示较晚照片时，还要警惕把“症状出现较慢”与“最终完全不发病”混为一谈。

## 6　营养方式帮助提出问题，不能直接代替机制

第1章介绍了活体营养型、坏死营养型和半活体营养型。这里把它们放回过程：活体营养型依赖活宿主组织取得资源；坏死营养型利用被杀死的组织；典型半活体营养型在侵染过程中存在营养关系变化。营养方式描述的是与宿主的关系，不是某一种形态、某一个分类群或一个激素的专属标签。

白粉菌和锈菌适合帮助理解对活组织的依赖；灰霉菌适合帮助理解组织死亡可能被病原利用；稻瘟病研究则常用于比较侵染阶段的改变。细菌没有与真菌完全相同的菌丝阶段，病毒、线虫的循环也各有特点。不要把“先侵入、后来叶片坏死”自动当成已经证明半活体营养阶段转换。

同样，SA与活体营养病原防御、JA/ET与部分坏死营养病原或昆虫防御之间，是常用的入门联系。具体输出仍依赖宿主、组织、阶段和信号网络，详见[第5章](../part2-分子机制/ch05-激素信号网络.md)。细胞死亡在一种关系中限制病原，在另一种关系中却可能增加可利用组织；因此HR照片也必须接回具体病理背景。

## 自测与解析

**1. 在叶片表面检测到病原DNA，能否证明已经建立感染？**

不能。它可能来自叶表、失活材料或尚未建立的接触。位置、活性及持续发展的证据需要分别判断。

**2. 一个突变体叶内病原负担降低，能否据此认定气孔防御增强？**

不能。负担降低也可能来自叶内限制增强。要解释进入环节，比较必须确实包含并能区分这一环节。

**3. “初侵染”是否表示某种病原在人类历史中第一次感染？**

不是。它相对于所定义的生长季或流行周期；再侵染关注本周期内新产生接种体造成的感染。

**4. 病斑持续扩大，就足以把病害判为多循环吗？**

不足。病斑扩大可以只是同一感染部位的扩展；多循环需要在所讨论周期内反复完成接种体产生、传播和新感染。

**5. 症状出现的时间与产生传播单位的时间是否相同？**

不必相同。潜育期以症状出现为终点，潜伏期的流行学定义通常以进入可传播阶段为终点；读文献时应核对作者定义。

**6. 一个材料的HR更强，是否说明它对坏死营养型病原也更抗病？**

不能。宿主死亡可能被某些病原利用。抗病判断需要与该病原相匹配的负担、病害和宿主损失证据。

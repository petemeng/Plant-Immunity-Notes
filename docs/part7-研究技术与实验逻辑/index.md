## 第一次读原图，可以按这个顺序

1. **找到图号和面板字母。** 正文说Figure 2c，就先定位c；不要把同图a、b的纵轴带进来。
2. **说清横轴与纵轴。** 哪些是基因型、处理或配对？纵轴是相对表达、发光、富集、数量还是比例？没有坐标的图，就看检测标签和分组。
3. **先看对照，再看主比较。** Input、空载、背景抗体、基本生长和上样参照各有用途，不是可互换的“阴性”。
4. **分开写观察与解释。** 先写“实际检测到什么”，再写“支持什么命题”。对于看不出的精确数值，不自行估算成结果。
5. **回原文核对统计信息。** 样本量、误差条、统计符号和重复层级以图例和原文为准；不同面板即使都写n=3，也未必代表相同实验单位。

| 容易混淆的词 | 本篇怎样区分 |
|---|---|
| 出版原图／原始数据 | 本篇展示作者发表的图；它们通常经过作者整理，不能等同于仪器输出、完整未裁剪胶片或全部原始测量 |
| Input／IP／IB | 分别关注富集前输入、免疫富集和免疫印迹检测；先确认捕获谁、再确认检测谁 |
| Split-LUC／Dual-LUC | 前者通过片段互补考察候选关联；后者通常比较报告酶和参照酶的输出 |
| 显著性／效应大小 | 统计判断与变化幅度回答不同问题；需要同时查看比较对象和原文统计说明 |
| 代表图／独立重复 | 一张照片或条带不自动告诉你重复次数；重复信息需要从图例和原文核对 |

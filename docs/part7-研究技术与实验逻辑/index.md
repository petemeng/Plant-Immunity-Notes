# 研究技术与实验逻辑：从具体案例读懂一张图

看到一张Co-IP条带图，先看哪条泳道？Y2H中的酵母长出来了，为什么还不能立即宣布互作？一个基因的相对表达变为四倍，为什么不代表抗病能力也变为四倍？本篇把这些问题放进具体案例，逐步连接**研究问题、逐组观察、关键对照、解释和结论**。

三章保留方法原理与自测，并各增加四个分步案例，共12个。先用明确标注的虚拟结果练习算术和比较，再进入真实的植物免疫论文。虚拟数值不对应实际样本，也不包含生物学显著性；真实案例注明论文及能够核对的图或图例，不从图片外观猜造原始数字。

## 跟着案例做一次完整推理

第一遍先读表头、分组和图注，暂时不看解释。给每个数值写清“它测到了谁”；遇到比值时，把分子和分母分别写出来。第二遍按基准组、比较组、背景组检查差异，思考哪种替代解释仍然成立。最后再阅读案例给出的结论，对照自己是否把一个局部结果扩大为普遍机制。

可以用这句格式写读图笔记：“在所比较的背景中，实际检测到……；……对照帮助排除了……；因此支持……，但尚不能确定……。”初学时不必追求句子复杂，先确保每个判断都能指回一项观察。

| 常用词 | 本篇的统一用法 |
|---|---|
| Input、IP、IB | 分别指富集前输入、免疫富集和免疫印迹检测；三者不是同一步 |
| Co-IP、Y2H | 分别读取共沉淀关联和异源转录报告，不把两者直接写成同一种测量 |
| RT-qPCR、Cq、ΔCq | 相对转录本定量及其阈值、参照计算；解释依赖效率与参照假设 |
| Split-LUC、Dual-LUC | 前者是荧光素酶片段互补，后者通常比较两个报告酶输出 |
| 归一化、独立重复 | 前者建立比较尺度；后者提供独立来源的变异信息，不能互相替代 |

完成案例后，回到各章末尾的带解析自测。想把技术放回机制研究，可继续读[第3章受体信号](../part2-分子机制/ch03-受体与信号转导.md)、[FLS2研究史](../history/genes/FLS2.md)与[SARD1/CBP60g研究史](../history/genes/SARD1-CBP60g.md)。
